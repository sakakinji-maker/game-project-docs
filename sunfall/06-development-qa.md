# 개발자 기능·QA

[목차](README.md) · 기준 2026-11-03

## 개발 환경과 구조

- Unity: **6000.3.27f1** — 프로젝트의 `ProjectSettings/ProjectVersion.txt` 기준.
- C#과 Unity Input System 사용.
- 현재 화면은 `SunfallGame` partial 클래스의 IMGUI 기반 1280×720 논리 캔버스를 사용합니다.
- `Assets/Sunfall/Core/`: 전투·스테이지·적·장비·성장·스킬 모델.
- `Assets/Sunfall/Runtime/`: 입력, 화면, 이미지 표현, UI, 대화, PlayerPrefs 저장.
- `Assets/Sunfall/Editor/`: 이미지 임포트 등 에디터 처리.
- `Assets/Sunfall/Tests/EditMode/`: 회귀 테스트 소스.
- `Assets/Sunfall/Resources/`: 실제 게임 이미지·아이콘·초상화 등.
- `docs/`: 기능별 작업 기록. 과거 수치와 현재 수치를 구분해서 읽어야 합니다.

이 저장소의 기존 애프터라이트 기획에 적힌 Unity 버전과 SUNFALL 프로젝트 버전은 서로 다른 프로젝트의 정보입니다.

## 개발자 키

Unity Editor 또는 Development Build에서만 활성화됩니다. Game 창에 키보드 포커스를 둡니다.

| 키 | 동작 |
|---|---|
| F1 | 1스테이지 숲 입구 |
| F2 | 2스테이지 잿빛 성문 |
| F3 | 3스테이지 대성당 진입로 |
| F4 | 4스테이지 왕관의 외벽 |
| F5 | 5스테이지 거울 정원 |
| F6 | 6스테이지 밤의 기단 |
| F7 | 7스테이지 빛을 잃은 왕궁 |
| F8 | ‘8스테이지 미구현’ 안내. 현재 맵 유지 |
| F10 | 진행 데이터 초기화 후 시작 화면 |

F1~F7은 타이틀·마을·전투·결과·대화·보스 연출·메뉴 상태에서도 해당 첫 전투방으로 이동합니다. 장비·강화·재화·성장·획득 스킬·장착 슬롯을 유지하고 체력/쿨타임을 회복합니다. 투사체·상태 이상·현재 보스 연출·미선택 보상은 새 방 상태로 정리합니다.

건너뛴 보스를 처치한 것으로 기록하거나 스킬을 자동 지급하지 않습니다. 이동으로 중단한 대사는 시청 완료로 저장하지 않습니다. 키 재지정 중에는 이동/초기화가 발동하지 않습니다.

F10은 장비·골드·성장·현재 모험·스토리 시청 기록을 지웁니다. 키 배치·음량 설정은 유지합니다. 일반 출시 빌드에서는 개발자 기능이 비활성입니다.

## 검증 상태

**최신 검증은 컴파일만 수행했습니다. Unity Play, 게임 QA, 테스트 실행, 플레이어 배포 빌드는 수행하지 않았습니다.**

아래는 로컬 프로젝트에 남아 있는 변경별 컴파일 로그입니다. 이 문서 저장소에 로그 원본이나 실행 파일을 올린 것은 아닙니다.

| 변경 | 로그 경로 | 결과 |
|---|---|---|
| 공격 장비 보너스 상향 | `Temp/EquipmentBonusCompile/compile.log` | Core/Runtime/Editor/Tests 통과 |
| 1층 도트 장식 교체 | `Temp/ForestPropsCompile/compile.log` | 동일 4종 통과 |
| 2층 도트 스타일 통일 | `Temp/Stage2PixelStyleCompile/compile.log` | 동일 4종 통과 |
| 개발자 스테이지 이동 | `Temp/DeveloperChapterCompile/compile.log` | 동일 4종 통과 |

컴파일 스크립트는 프로젝트 상위 `tools/Compile-AttackArt.ps1`입니다. Unity 내장 Roslyn과 로컬 Library 참조를 사용하므로 이 문서 저장소만 내려받아 실행할 수 있는 도구는 아닙니다.

## 사용자 QA 체크리스트

### 전투와 수치

- [ ] 검 1·2·3타와 공중 베기에 크기 변화·잘림·위치 튐이 없는지 확인.
- [ ] 장검 미장착 / +0 / +5에서 기본 검 피해 24 / 31.2 / 40.8 확인. 공격력 성장 없는 기준.
- [ ] 화로 미장착 / +0 / +5에서 불씨 파동 60 / 75 / 96 확인. 마력 성장 없는 기준.
- [ ] 3타·범위 스킬·다단히트·처치 직전 초과 피해 숫자 확인.
- [ ] 구르기 무적, 하단 발판 이동, 사슬 끌어오기, 보스 끌기 제한 확인.

### 진행과 보상

- [ ] 각 방 몬스터가 남으면 출구가 잠기는지 확인.
- [ ] 문 앞 ↑만으로 이동하고 공중/거리 밖에서 오작동하지 않는지 확인.
- [ ] 1~7층 보스 등장·2페이즈·처치·스킬 선택·상자·포탈 순서 확인.
- [ ] 스킬 선택 전 출구 제한, 기존 스킬 유지, 슬롯 4개 제한 확인.
- [ ] 상자의 즉시 회복·미보유 장비 지급·중복 개봉 차단 확인.
- [ ] 7층 결말 뒤 존재하지 않는 8층으로 진입하지 않는지 확인.

### 화면과 저장

- [ ] 1·2층 배경/발판/장식의 도트 크기, 봉인 경계, 다양한 화면비 확인.
- [ ] 보스와 NPC의 상황별 초상화 및 대화 중 전투 정지 확인.
- [ ] 서장을 본 뒤 종료/재실행 시 다시 재생하지 않는지 확인.
- [ ] 장비·강화·골드·성장·설정 저장 복원 확인.
- [ ] 마을 점프/스킬과 NPC Space 상호작용이 충돌하지 않는지 확인.

### 개발자 도구

- [ ] F1~F7 각각 첫 방에서 시작하고 체력/쿨타임이 회복되는지 확인.
- [ ] 획득 스킬·장착 슬롯·장비·성장이 유지되는지 확인.
- [ ] 대화/사망/보스 연출 중 이동 후 이전 상태가 남지 않는지 확인.
- [ ] F8 안내만 표시하며 맵과 진행 데이터가 유지되는지 확인.
- [ ] 키 재지정 중 기능키를 눌러도 이동/초기화되지 않는지 확인.
- [ ] F10 초기화 및 일반 출시 빌드의 개발자 기능 비활성 확인.

## 다음 작업 후보

사용자 QA에서 재현된 오류를 우선 수정합니다. 이후 3~7층 미술 통일, 스테이지별 난이도·성장 경제 조정, 전용 음향/음악, 실제 배포 빌드 검증을 검토할 수 있습니다. 현재 배경 음악은 코드에서 생성하는 임시 루프입니다. 8스테이지는 별도의 기획·구현 요청이 필요합니다.

이 목록은 후속 후보이며 이미 제작 완료된 기능으로 간주하지 않습니다.
