## 기본 조작

| 입력 | 동작 |
|---|---|
| ← / → | 이동 |
| Ctrl | 검 공격. 누르면 연속 공격 |
| Alt | 점프 |
| ↓ + 점프 | 발판 아래로 내려가기 |
| Shift | 구르기 |
| F / Q / E / R | 장착 스킬 슬롯 1 / 2 / 3 / 4 |
| Space | 가까운 NPC 상호작용·대화 진행 |
| ↑ | 문/포탈 앞 이동, 보물상자 상호작용 |
| I | 인벤토리·능력치 |
| K | 스킬창 |
| Esc | 메뉴 닫기/일시정지 |

이동·공격·점프·구르기·4개 슬롯의 총 9개 조작은 설정에서 변경할 수 있습니다. 좌우 Ctrl/Alt/Shift를 지원합니다. 고정 기능 및 개발자 예약 키는 중복 지정하지 못합니다.

## 검과 구르기

| 동작 | 피해 배율 | 동작 시간 | 준비 시간 |
|---|---:|---:|---:|
| 지상 1타 | 검 피해 ×1 | 0.24초 | 0.06초 |
| 지상 2타 | 검 피해 ×1 | 0.26초 | 0.06초 |
| 지상 3타 | 검 피해 ×1.6 | 0.40초 | 0.10초 |
| 공중 베기 | 검 피해 ×1 | 0.30초 | 0.06초 |

기본 피해 24에 공격력 성장과 장검 보너스를 적용합니다. 3타는 사거리가 늘고 일반 경량 적을 밀어냅니다. 각 타격은 준비 시간이 끝날 때 범위 안의 적에게 한 번 적용하며, 공중 공격도 높이 조건을 검사합니다.

구르기는 지상에서 시작하며 동작 0.35초, 초기 무적 0.2초, 기본 재사용 0.7초입니다. 약 2.3 거리 이동하며 장화로 재사용 시간을 줄일 수 있습니다. 행동 취소와 이동 방향 고정 규칙을 사용합니다.

## 스킬 획득·장착

- 새 모험은 불씨 파동으로 시작합니다. 모든 보스 스킬을 처음부터 제공하지 않습니다.
- 각 층 보스 이후 후보 2종 중 **하나를 직접 선택**합니다. ‘운명에 맡기기’는 무작위 선택입니다.
- 같은 모험에서 다음 층으로 넘어가도 얻은 스킬은 유지됩니다.
- K 스킬창에서 설명, 기본/장비 적용/남은 쿨타임을 확인하고 최대 4개를 장착합니다.
- 슬롯 이동이나 해제·재장착으로 쿨타임을 우회하지 않습니다.
- 새 스킬은 빈 슬롯에 자동 장착됩니다. 가득 찼다면 스킬창에서 교체합니다.
- 마을 귀환 시 직전 모험에서 얻은 스킬을 연습할 수 있지만, **새 모험을 시작하면 보스 스킬은 다시 획득**합니다.
- 개발자 F1~F7 이동은 현재 획득 스킬과 장착 슬롯을 복사합니다.
