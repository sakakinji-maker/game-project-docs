> **개발 진행 중인 프로젝트입니다.** 1~7스테이지까지 구현했고 계속 수정·추가하고 있습니다. 현재 PC(키보드) 기준이며 모바일은 아직 대응하지 않았습니다.

> 구현 현황 기준: **2026-11-05** · Unity **6000.3.27f1** · C#
>
> 로컬 Unity 프로토타입의 코드와 에셋 연결을 기준으로 정리했습니다. **구현·컴파일 완료와 플레이 QA 완료는 다릅니다.** 최신 변경은 컴파일만 확인했으며, 아래 QA 항목은 사용자 확인 대상입니다.

## 게임 개요

태양이 사라진 고딕 세계에서, 주인공은 왕실 봉인에 붙잡힌 양어머니를 찾아 일곱 스테이지를 돌파합니다. 검 3연타와 공중 베기, 구르기, 장착한 마법을 조합하는 2D 횡스크롤 액션입니다. 보스를 처치하면 별실을 회수하고 하늘에 금빛 봉합 자국을 남깁니다.

Skul은 넓은 횡스크롤 방과 액션 흐름의 참고작입니다. 게임의 제목·등장인물·양어머니 구출 이야기·별실 봉합 설정은 SUNFALL 기준으로 정리합니다.

**시작 화면 → 서장 → 불씨 마을 → 전투방 3개 → 보스 → 스킬 선택·상자 → 다음 스테이지 → 7층 결말**

## 현재 구현 범위

| 분야 | 현재 상태 |
|---|---|
| 캠페인 | 1~7스테이지, 각 전투방 3개 + 보스방: 총 28개 방 |
| 8스테이지 | 미구현. F8은 안내만 표시 |
| 전투 | 검 3연타, 공중 베기, 구르기, 마법 시전 |
| 일반 적 | 근접병·궁수·중갑병 악마 |
| 보스 | 7종, 등장/처치 대화·연출, 패턴과 2페이즈 |
| 스킬 | 기본 1종 + 보스별 후보 2종씩, 총 15종. 최대 4개 장착 |
| 장비 | 5종, 4개 부위, 구매·장착·해제·최대 +5 강화 |
| 성장 | 처치 골드/경험치, 레벨, 공격력·마력·체력·방어력·민첩 |
| 마을 | 대장장이·상인·아린, 대화·서비스, 점프·스킬 연습 |
| 연출/UI | 고딕 타이틀·HUD·이름표·설정, 스킬 아이콘, 표정 초상화 |
| 저장 | 장비/강화·재화/성장·스토리 시청 기록·설정 |
| 개발자 도구 | F1~F7 첫 방 이동, F8 미구현 안내, F10 진행 초기화 |

증강 선택 시스템은 현재 게임 흐름에 사용하지 않습니다. 보스 스킬은 **두 후보 중 하나를 직접 선택**하며, 선택 화면의 무작위 선택 기능도 있습니다. 과거의 전용 스킬 키 Q/E/R/T/Y/U/O/P 설명 대신 **4개 슬롯 F/Q/E/R**이 현재 기준입니다.

## 가장 최근 변경

2026-11-05: 3~7층 배경·보스 개편 및 렌더링/봉합/4~6층 수정까지 게임 프로젝트에 반영했습니다. [최신 수정 기록](../game/Sunfall/docs/RENDERING_STAGE_FIXES_2026_11_05.md). 컴파일 통과, 최신 플레이 QA 미실행.

이전 반영 내역:

- 장검: 검 피해 기본 +30%, 강화당 +8%p, +5에서 +70%.
- 화로의 심장: 마법 피해 기본 +25%, 강화당 +7%p, +5에서 +60%.
- 장착 전후 능력치와 장비 기여분, 실제 타격 계산에 따른 피해 숫자 표시.
- 1스테이지의 사각형 기반 장식을 도트 이미지 6종으로 교체.
- 2스테이지 전투방 3개·보스방과 봉인 구조물을 1스테이지 스타일로 재제작.
- F1~F7 개발자 이동과 F8 미구현 안내 적용.

이 폴더는 **문서 스냅샷**입니다. 실제 Unity 소스·씬·이미지·설정은 [game/Sunfall](../game/Sunfall/)에, 여는 방법은 [게임 실행 안내](../game/README.md)에 있습니다. 개인 저장 데이터는 포함하지 않습니다. EXE 배포본은 [Windows QA Release](https://github.com/sakakinji-maker/game-project-docs/releases/tag/sunfall-qa-2026.11.05-1)에서 별도로 받습니다. 문서의 `Assets/...` 경로는 해당 Unity 프로젝트 기준입니다. `Temp/...`는 캐시 제외로 업로드되지 않습니다.
