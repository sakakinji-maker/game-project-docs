# SUNFALL 기획·제작 요청·플레이 QA 활동 기록

[문서 목차](README.md) · [플레이 QA 누적 기록](../qa/sunfall-user-qa-history.md) · [최근 결함 상세](../qa/sunfall-regression-2026-11-06.md)

정리 기준: 2026-11-06. 개발 과정의 기록에서 확인되는 요청과 피드백을 단계별로 묶었습니다. 개별 작업의 정확한 수행일이 없는 경우 임의 날짜를 붙이지 않았습니다. 현재 소스의 구현 상태와 당시 본인의 관찰은 구분합니다.

## 본인이 담당한 일

- **게임 방향 결정:** 검과 마법을 사용하는 주인공, 어두운 고딕 분위기, 사라진 태양과 양어머니 구출을 연결하는 이야기 선택.
- **기능 및 규칙 기획:** 검 3연타·공중 베기·구르기, 보스 보상과 스킬 선택, 장비·강화·골드·능력치 성장, 방 이동과 저장 규칙 결정.
- **미술 방향 제시:** 주인공·옷·공격 자세·NPC·악마·각 층 배경 및 보스 참고 이미지 제공. 1스테이지를 기준으로 다른 층의 품질과 도트 분위기를 맞추도록 반복 피드백.
- **직접 플레이 QA:** 캐릭터 가시성, 공격 크기·잘림·끊김, 스킬 표현, 적 인식, 포탈 진행, 저장, 봉합·구출·엔딩 문제를 관찰하고 스크린샷과 함께 제보.
- **작업·검증 범위 관리:** Codex에는 구현과 컴파일까지 요청하고 실제 플레이·QA는 직접 맡도록 지정. F1~F8 및 F10 개발자 기능, 다른 PC용 EXE 배포 요청.

코드 수정·이미지 생성·컴파일·문서 정리는 Codex의 지원을 받았습니다. 따라서 여기서는 본인의 기획·관찰·판단과 도구가 수행한 구현·검증을 별도로 기록합니다. 자동 테스트 작성이나 컴파일을 본인 수동 QA 통과 실적으로 합산하지 않습니다.

## 반복 QA에서 한 판단

1. **부분 개선과 남은 결함을 분리했습니다.** “이제 캐릭터는 보여” 뒤에 공격 프레임의 잘림·위치 튐을 다시 지적했고, “이동은 부드러워졌는데” 뒤에는 공격 모션의 끊김을 별도 문제로 제시했습니다.
2. **최초 증상과 재발을 연결했습니다.** 점프 공격 시 커짐과 작아짐, 스킬의 박스 표현과 정지 이미지 같은 움직임, 봉합선의 위치와 가시성을 반복 관찰했습니다.
3. **스크린샷으로 조건을 구체화했습니다.** 어느 스테이지의 어떤 구조물인지 구분해 사슬 고정점, 거울 줄무늬, 어머니 연결선과 처치 이후 상태를 전달했습니다.
4. **버그와 개선 요구를 구분했습니다.** 계산 누락 가능성을 먼저 확인하도록 요청한 뒤 장비 보너스 상향을 별도 밸런스 요청으로 이어갔습니다. 고딕 분위기와 이미지 품질 요청은 모두 기능 오류로 취급하지 않습니다.
5. **검증 경계를 명시했습니다.** 컴파일 통과와 실제 플레이 통과를 구분하고, 최신 수정의 재검증을 직접 진행하는 방식으로 운영했습니다.

## 확인된 결과와 아직 남은 확인

기록에서 명시적으로 확인된 내용은 초기 전투 기능의 정상 동작, 캐릭터가 다시 보임, 이동이 부드러워짐, 당시 Unity에 오류가 없다는 응답입니다. 각 확인은 해당 시점·해당 항목에만 적용됩니다. 최신 모션·봉합·엔딩 전체가 본인 QA를 통과했다고 해석하지 않습니다.

최근 변경의 검증 범위는 [2026-11-06 수정·컴파일 기록](../game/Sunfall/docs/RELEASE_NOTES_2026_11_06.md)에 정리했습니다. 최신 소스에는 새 변경이 포함되지만 기존 2026-11-05 EXE Release에는 포함되지 않습니다.
