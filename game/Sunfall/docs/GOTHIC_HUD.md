# 고딕 체력바·스킬 HUD (2026-10-28)

## 디자인

- 플레이어: 꺼진 태양과 불씨 문장, 어두운 금속·낡은 금색의 다층 테두리, 뾰족한 끝 장식을 적용했습니다. HP가 줄어도 테두리는 고정되고 내부 게이지만 감소합니다.
- 기본 생명색은 청록, 30% 이하에서는 붉은색과 `생명 · 위험` 문구로 표시합니다. HP 수치와 공격력은 유지했습니다.
- 보스: 붉은 체력 게이지, 고딕 테두리, 가운데 절반 체력 표식. 2페이즈에서는 게이지가 더 밝은 붉은색으로 바뀝니다. 보스 이름·페이즈·HP 수치·귀환문 안내를 유지했습니다.
- 하단: 구르기·불씨 파동·검·점프를 원형 금속 문장으로 표현했습니다. 각 문장에 구르기 화살표, 불꽃, 검, 상승 화살표 아이콘을 직접 그립니다.
- 재사용 대기 중에는 아이콘을 어둡게 하고 남은 초를 표시합니다. 시계 방향으로 채워지는 외곽선도 재사용 가능 시점을 나타냅니다. 구르기는 청록, 불씨는 주황색으로 구분합니다.
- PC에서는 각 문장 아래에 현재 설정된 키를 표시하고, 이동·발판 내려가기·문 이동 안내를 하단 왼쪽에 배치했습니다.
- 터치 조작은 기존 입력 범위를 유지합니다. 좌우 이동 버튼과 전투 중 문 이동 버튼도 같은 디자인으로 맞췄습니다.

## 구현

`Assets/Sunfall/Runtime/SunfallGame.Hud.cs`에서 기존 IMGUI에 맞춰 문장, 금속 테두리, 아이콘과 게이지를 그립니다. 기존 사각형 HP·스킬 표시를 대체했으며 외부 이미지나 폰트 의존성을 추가하지 않았습니다.

장식은 픽셀 단위 도형과 선으로 구성하며, 스킬 판정·쿨다운·이동·전투 수치는 변경하지 않았습니다. 미니맵과 설정 화면은 기존 기능을 유지합니다.
