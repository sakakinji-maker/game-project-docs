# 4스테이지 — 왕관의 심장부

## 진행

아우렐 처치 대사/연출 뒤 열린 포탈 앞에서 지상 ↑를 누르면 4스테이지로 이동합니다. 보스 생존 중·연출 중·공중에서는 이동할 수 없습니다. 상자 개봉은 선택이며 포탈 이동 시 미개봉 물약이나 장비를 자동 지급하지 않습니다.

같은 RunModel을 사용하므로 현재 HP·최대 HP·장비 소유/장착/강화·골드·경험치·성장·처치 수·시드를 유지합니다. 기본 불씨 파동, 1보스의 잿불 창/홍염 고리, 2보스의 포박 사슬/사슬 강림, 3보스의 태양의 창/여명의 폭발을 모두 유지합니다. 사용자 키 설정도 유지됩니다.

기존 방 이동처럼 X=2, Y=0에서 시작하며 공격·시전·투사체·사슬·구속·잔상·쿨다운·이전 보스·상자 상태와 카메라·입력 큐를 정리합니다. 진입 무적 1초, 자동 체력 회복 없음. 영구 성장 저장과 새 모험 초기화 규칙은 변경하지 않습니다.

## 방 구성

| 방 | 적 배치 | 발판 (시작 X, 너비, 높이) |
|---|---|---|
| 왕관의 외벽 | 근접 3 / 궁수 3 / 중갑 2 = 8 | (8,8,1.6), (13,8,3.2), (27,10,1.6), (41,8,1.6), (46,9,3.2) |
| 역광의 도관 | 근접 4 / 궁수 3 / 중갑 2 = 9 | (7,8,1.6), (12,8,3.2), (17,9,4.8), (38,9,4.8), (43,8,3.2), (48,9,1.6) |
| 심장 봉인실 | 근접 4 / 궁수 3 / 중갑 3 = 10 | 도관의 6개 발판 + (28,8,1.6) |

가로 64, 출구 X=61. 계단 높이 차는 1.6, 겹친 구간으로 기본 점프만으로 상층까지 접근할 수 있습니다. 상층 적은 지지 발판 범위 안에서 순찰합니다. 일반 적 HP는 원본의 1.6배(근접 70.4 / 궁수 57.6 / 중갑 160), 공격 패턴·골드·경험치는 기존과 같습니다. 태양 관통 공격과 사슬/광역 마법을 활용할 수 있도록 지상 적 무리와 상층 궁수를 조합했습니다.

각 방 전원 처치 후 지상 문 앞 ↑로 진행합니다. 단순 접촉·공중·구르기로 봉인된 문을 넘어갈 수 없습니다. 심장 봉인실 전원 처치 뒤 ↑를 누르면 왕관의 심장 제단으로 이동합니다. 바르칸(HP 780)을 처치하면 보물상자와 5스테이지 거울 성역 포탈이 열립니다. 최종 구출 결말은 7스테이지 솔베인 처치 후에 이어집니다. 최신 상세는 SEVEN_CHAPTER_CAMPAIGN.md를 참조하세요.

## 배경과 이야기

기존 먼 배경 위에 코드로 검붉은 금속 기둥·왕실 깃발·황동 바닥 띠·리벳을 추가했습니다. 외벽은 왕실 아치와 깃발, 도관은 거꾸로 흐르는 빛과 회전 기구, 봉인실은 사슬에 묶인 붉은 심장 문장과 금빛 별실로 구분합니다. 모든 장식은 배경이며 충돌은 실제 발판만 처리합니다. 배경은 기존 코드 장식을 확장했고, 바르칸은 전용 8포즈 도트 시트를 생성했습니다.

최초 진입 대사 4쪽은 아우렐이 지키던 바깥 봉인에서 왕의 명령이 남은 안쪽 심장부로 넘어가는 장면입니다. 양어머니가 직접 대답하며 주인공은 새로 얻은 태양의 힘으로 마지막 매듭을 향하겠다고 말합니다. Space/다음 버튼으로 진행하며 대화 중 전투·연출을 멈춥니다. 전체 대본은 STORY_DIALOGUE.md에 기록했습니다.
