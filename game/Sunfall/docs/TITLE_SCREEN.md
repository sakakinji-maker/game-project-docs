# SUNFALL — 별을 꿰매는 마녀: 시작 화면

2026-11-01. README와 기존 스토리에 기록된 제목을 사용합니다.

- 큰 `SUNFALL` 로고와 `별을 꿰매는 마녀` 부제, 어머니에게 돌아갈 길을 꿰매는 이야기를 담은 짧은 문구.
- 기존 `World/EmberVillageV1` 배경 위 어두운 그라데이션, `Hero/HeroPortrait`를 배치한 고딕 액자.
- 상단의 금빛 봉합 자국과 천천히 흐르는 빛, 작은 금빛 입자. 기존 이미지를 GUI에서 배치하며 원본 PNG는 수정하지 않았습니다.
- 세로 메뉴: `이야기 시작`, `환경 설정`. 선택 항목은 금빛 테두리와 마름모 표식으로 강조합니다.
- 마우스·터치 클릭, ↑/↓ 선택, Enter/숫자패드 Enter/Space 결정. 타이틀이 표시되고 설정 창이 닫힌 경우에만 메뉴 키를 처리합니다.
- 시작 버튼은 기존 서장 대사 → 불씨 마을로 이어집니다. 설정은 기존 키 변경·소리 메뉴에 연결됩니다. 시작 입력 직후 기존 Block 처리를 거쳐 서장 대사가 동시에 넘어가지 않게 합니다.
- WORKING TITLE, 첫 전투 프로토타입, 테스트용 안내 문구를 시작 화면에서 제거했습니다.

구현: `Assets/Sunfall/Runtime/SunfallGame.Title.cs`. 기존 `SunfallGame.cs`의 타이틀 메서드를 옮기고 Update에 메뉴 입력을 연결했습니다. 1280×720 논리 화면과 기존 safe-area 비율 조정을 사용합니다.

제품 설정의 내부 productName 및 저장 키는 변경하지 않았습니다. Unity PlayerPrefs 저장 위치가 제품명에 종속되므로 시작 화면 브랜딩 변경 때문에 기존 설정·장비·성장이 사라지는 것을 피합니다.

컴파일 로그: `Temp/TitleScreenCompile/compile.log`. Unity Play, 게임 QA, 테스트 실행, 플레이어 빌드는 하지 않습니다.
