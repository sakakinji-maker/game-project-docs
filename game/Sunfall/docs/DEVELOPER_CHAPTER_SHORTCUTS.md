보스 연출, 미선택 보상, 상자 상태를 제거합니다. 장비·강화·골드·성장은 기존
객체를 유지하고 이미 배운 스킬과 장착 슬롯을 복사합니다. 건너뛴 보스의
스킬이나 보상은 자동 지급하지 않습니다. 현재 대화는 닫지만 시청 완료 기록을
쓰지 않으며, 스테이지 이동 자체로 저장 데이터나 스토리 기록을 초기화하지 않습니다.
첫 방의 몬스터 처치 및 출구 조건은 정상 규칙을 따릅니다.
