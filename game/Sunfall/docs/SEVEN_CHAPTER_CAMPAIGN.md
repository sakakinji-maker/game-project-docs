# 4~7스테이지 캠페인

## 진행과 유지 항목

3층 아우렐 → 4층 바르칸 → 5층 리세아 → 6층 녹티스 → 7층 솔베인 순서입니다. 각 층은 전투방 3개와 보스방 1개입니다. 전투방의 모든 일반 적을 처치하고 지상 문 앞에서 ↑를 눌러야 진행됩니다. 보스방은 처치 대사와 붉은 입자 소멸 후 포탈과 보물상자가 열립니다. 마지막 보스 처치만으로 종료하지 않으므로 상자를 열어 본 뒤 최종 포탈에서 ↑로 결말을 볼 수 있습니다. 8층은 생성하지 않습니다.

동일 RunModel을 계속 사용합니다. 불씨 파동, 1층 보상(Q 또는 E), 2층 보상(R), 3층 보상(T), HP, 소유/장착/강화 장비, 골드와 영구 성장을 유지합니다. 4~7층에서는 각 보스에 맞는 두 스킬 중 하나를 직접 선택하거나 운명에 맡기기로 50% 무작위 획득합니다. 기존 스킬을 다시 추첨하거나 덮어쓰지 않습니다. 선택을 마쳐야 다음 포탈을 사용할 수 있습니다. 새 도전을 시작하면 기존 규칙대로 스킬을 다시 획득합니다. 기본 키 Y/U/O/P와 상세는 LATE_BOSS_SKILLS.md를 참조하세요.

각 방 이동 시 위치와 공격/효과/재사용 대기시간을 정리합니다. 자동 회복은 없고, 보스 상자의 물약은 기존대로 즉시 최대 40 회복합니다. 상자는 보유하지 않은 장비가 있으면 1개를 지급하며, 모두 보유한 경우 추가 장비는 지급하지 않습니다. 상자 개봉은 선택입니다.

가로 64, 지상 출구 X=61. 일반 적 체력 배율은 4층 1.6 / 5층 1.8 / 6층 2.0 / 7층 2.2입니다. 5~7층은 지상 근접 3+중갑 3, 상층 궁수 2로 시작하고, 두 번째 방에는 궁수 1, 세 번째 방에는 지상 근접 1을 추가합니다. 발판 높이 차는 1.6으로 기본 점프만으로 올라갈 수 있습니다.

5층은 좌우 2단 발판과 중앙 낮은 발판, 6층은 양쪽 3단 계단, 7층은 중앙 2단 제단과 양쪽 낮은 발판을 사용합니다. 두 번째 방은 중앙 낮은 발판을 잇고 세 번째 방은 입출구의 낮은 발판을 더합니다. 높은 궁수의 순찰 범위 전체를 발판이 받칩니다. 지상은 연속되어 낙사 지형이 없습니다.

기존 먼 배경 위에 고딕 기둥과 장식을 그립니다. 5층은 금이 간 뾰족 거울창, 6층은 초승달과 별빛·사슬 종루, 7층은 검붉은 왕실 깃발과 사슬에 묶인 검은 태양입니다. 배경 장식에는 충돌이 없습니다.

모든 보스는 중앙 등장 연출을 공유합니다. 녹티스만 기본 높이 2.2에서 비행하며 급강하 후 다시 떠오릅니다. 왕실 보스마다 새 투명 8포즈 도트를 사용하고 프레임별 발 기준점과 넉넉한 검/망치 영역을 지정했습니다. 한 캐릭터에 고정 배율을 사용하며 기존 위치 보간과 포즈 블렌딩을 적용합니다. 그림은 `Resources/Demons/Stage4VarkanV1` ~ `Stage7SolveinV1`에 있습니다.

## 이야기와 결말

4층 장치를 멈추면 어머니의 몸을 묶은 명령이 느슨해지지만 기억이 거울에 갇혀 있음을 알게 됩니다. 5층에서는 주인공과 함께한 기억을 되찾고, 6층에서는 왕좌를 덮은 일식의 장막을 엽니다. 7층 왕 솔베인을 쓰러뜨린 주인공은 어머니를 묶은 매듭만 끊고 되찾은 별실과 태양빛으로 하늘을 다시 잇습니다. 다른 사람을 제물로 남기지 않고 함께 귀환합니다.

5~7층 진입 대사 각 3쪽, 4~6층 보스 등장/처치 각 4쪽, 7층 등장 5쪽/처치 7쪽. 기존 Space/다음 버튼으로 읽으며 대화 중 전투와 연출은 멈춥니다. 7층 처치 후 중앙 검은 태양이 금빛으로 밝아지고 사슬이 사라지며, 교차한 봉합 자국은 방을 떠날 때까지 남습니다. 마지막 포탈은 ‘함께 돌아온 아침’ 결과 화면으로 연결됩니다.
