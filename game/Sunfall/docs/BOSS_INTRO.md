# 중앙 보스 등장씬 (2026-10-28)

- 세 번째 전투방의 열린 포탈 앞에서 ↑로 보스방에 진입하면 3.6초 등장씬이 시작됩니다.
- 보스의 실제 생성 위치는 `WorldWidth / 2`(현재 X=32), 높이 Y=2.2입니다. 기존 비행 보스 도트를 사용하며 새로운 캐릭터 이미지나 별도 씬 파일은 추가하지 않았습니다.
- 처음 0.65초 동안 카메라가 맵 중앙을 비춥니다. 붉은 마법진·상승 입자·빛기둥이 나타나고, 0.7~1.6초 동안 보스가 아래에서 떠오르며 보입니다.
- 화면 상하단 시네마 바와 `붉은 날개의 수호자` 이름을 표시합니다. 마지막 0.85초에 카메라가 입구의 주인공에게 돌아옵니다. 실제 보스 좌표는 중앙에 유지합니다.
- 연출 시간과 상태는 Core 고정 스텝에서 관리하고 카메라·효과 표시에는 프레임 보간을 적용합니다.
- 연출 중 주인공 이동·점프·구르기·검·마법·문 이동, 보스 AI·공격·피해를 막습니다. 체력과 전투 쿨다운은 보존합니다.
- Esc 일시정지 및 포커스 상실에 따른 정지 중에는 연출도 멈춥니다. 종료 시 입력 큐와 자세 보간 기록을 비워 이전 입력이 발동하지 않도록 처리합니다.
- 종료 후 기존 비행·돌진·마법탄·2페이즈 전투를 사용하며, 보스 체력바는 전투 재개 직후부터 표시합니다. 보스가 다시 등장하는 것은 새로운 런에서 보스방에 재진입할 때뿐입니다.
