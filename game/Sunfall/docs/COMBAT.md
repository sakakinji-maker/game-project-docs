# 마검사 전투 초안

구현 기준: 2026-10-26. 수치는 플레이 QA 전의 초기값입니다.

## 조작

기본값은 방향키 이동, Ctrl 검, Alt 점프, Shift 구르기, F 불씨 파동입니다. Ctrl / Alt / Shift는 좌우 키를 모두 지원합니다. 조작 설정에서 여섯 동작 모두 변경·저장할 수 있으며 터치 미리보기에도 두 동작을 추가했습니다.

검은 누르고 있으면 연속 공격합니다. 구르기·마법은 한 번 누를 때 한 번 시도하며, 쿨다운 중 누른 입력은 자동으로 재사용되지 않습니다. 정지·설정·방 전환 시 남은 입력을 초기화합니다.

## 검

| 동작 | 기본 피해 배율 | 동작 시간 | 준비 시간 |
|---|---:|---:|---:|
| 지상 1타 | 100% | 0.24초 | 0.06초 |
| 지상 2타 | 100% | 0.26초 | 0.06초 |
| 지상 3타 | 160% | 0.40초 | 0.10초 |
| 공중 베기 | 100% | 0.30초 | 0.06초 |

기본 피해는 24입니다. 3타는 사거리가 2.5에서 3.2로 늘어나고 일반 적을 0.75만큼 밀어냅니다. 보스는 밀려나거나 경직되지 않습니다. 한 타격은 준비 시간이 끝나는 순간 범위 안의 적에게 한 번씩 적용됩니다.

각 타격이 시작할 때 방향을 고정하고 타격 사이에 방향을 바꿀 수 있습니다. 공격키를 떼면 이미 시작한 타격만 완료합니다. 동작 종료 후 0.32초 안에 다시 공격하면 다음 연타로 이어집니다. 점프·구르기·마법은 연타를 초기화합니다. 점프는 검 동작을 취소할 수 있습니다.

공중에서는 지상 연타 대신 가로 베기를 사용합니다. 높이가 맞지 않으면 지상의 적에게 맞지 않습니다. 공격·시전 중 이동 속도는 6에서 2.5로 감소합니다. 기존 신속 보상은 검의 동작·준비 시간을 함께 단축합니다.

## 구르기

- 지상에서만 시작, 0.35초 동작, 약 2.3 거리 이동(캐릭터 너비 약 3개).
- 시작 0.2초 피격 무적. 재사용 대기시간은 시작부터 0.7초.
- 이동 입력 방향으로 구르고, 입력이 없으면 바라보는 방향으로 구릅니다.
- 검의 준비·후딜 및 마법의 시전·후딜을 취소합니다.
- 구르는 동안 검·점프·마법은 사용할 수 없습니다.
- 적의 몸을 통과하며 방의 좌우 경계에서 멈춥니다. 발판 밖으로 나가면 중력이 적용됩니다.

## 불씨 파동

- 준비 0.2초 후 발사, 기본 검 피해의 250%, 마나 소모 없음.
- 사거리 7.5, 속도 16, 전방 관통. 같은 파동은 적마다 한 번만 피해를 줍니다.
- 지상·공중 사용 가능. 발사 높이는 캐릭터의 현재 높이를 따릅니다.
- 재사용 대기시간은 실제 발사부터 5초, 발사 후 후딜 0.18초.
- 발사 전에 구르면 파동과 쿨다운 모두 발생하지 않습니다. 발사 후 구르면 파동은 남습니다.
- 검 동작이 끝난 뒤 사용할 수 있으며, 검과 동시에 새로 입력하면 마법이 우선합니다.
- 지상에서 구르기와 마법을 동시에 입력하면 구르기가 우선합니다.
- 방 진입 시 동작·파동·쿨다운을 초기화합니다.

## 표시와 검증 범위

연타 단계별 베기 크기·색, 공중 베기, 구르기 회전·무적 색상, 마법 시전과 투사체를 기존 IMGUI 스타일로 표시합니다. HUD와 터치 버튼에 재사용 대기시간을 표시합니다.

Unity 내장 컴파일러로 Core / Runtime / Editor / Tests 어셈블리 컴파일 성공. 게임 실행, 자동 테스트, 플레이 QA와 빌드는 수행하지 않았습니다. 기존 전투 봇의 클리어 기록은 이 전투 변경 이전의 결과이며 새로운 공격 간격과 이동 제약에 대한 재검증이 필요합니다.
