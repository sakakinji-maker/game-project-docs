# 1탄 보스 스킬 보상 수정

- 새 모험은 불씨 파동만 사용 가능. 검·점프·구르기는 기존대로 사용합니다.
- 잿불 창 / 홍염 고리는 기본 잠김. HUD에 잠김과 1탄 보스 보상을 표시하고 준비 상태·조작 키를 표시하지 않습니다. 시뮬레이션에서 잠긴 스킬 입력을 무시하므로 키보드·터치·직접 입력 모두 시전, 효과, 쿨다운을 생성하지 않습니다.
- 1탄 보스 처치가 확정될 때 둘 중 하나를 같은 확률의 시드 기반 난수로 선택해 자동 획득합니다. 처치 연출에 획득 이름을 표시하고, 연출 후 7초간 안내와 실제 설정 키를 표시합니다. 연출 중에는 기존대로 조작을 잠급니다.
- 장비/물약 보물상자와 별개이며 상자를 열지 않아도 획득합니다. 한 보스의 처치 판정은 한 번만 처리하므로 연출·상자·추가 프레임으로 다시 추첨하지 않습니다.
- 스킬은 RunModel의 모험 상태입니다. 영구 성장 PlayerPrefs에 저장하지 않습니다. 사망·귀환 후 새 모험이나 같은 시드 재도전은 다시 두 스킬이 잠깁니다. 기존 장비·골드·능력치 저장에는 영향을 주지 않습니다.
- 후속 구현으로 보스 뒤 포탈은 2스테이지에 연결됩니다. 같은 모험의 RunModel을 유지하므로 획득한 스킬은 2스테이지 전투방에서도 계속 사용할 수 있습니다. 마을 귀환 후 새 모험을 시작할 때만 다시 잠깁니다. 상세: `CHAPTER_TWO.md`.
