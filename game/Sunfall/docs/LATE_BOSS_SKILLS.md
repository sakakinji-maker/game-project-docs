# 4~7층 보스 스킬 선택

보스 처치 대사와 소멸 연출이 끝나면 전용 스킬 두 개를 비교하는 선택창이 열립니다. 클릭/터치로 하나를 고릅니다. ‘운명에 맡기기’를 선택하면 같은 두 후보 중 50% 확률로 하나를 얻습니다. 확정은 한 번만 가능하며 취소·재추첨·다른 후보 추가 획득은 불가능합니다. 선택 중에는 게임 시간이 멈추고 이동/전투/상자/포탈/장비 변경이 차단됩니다. Esc로 일시정지와 설정은 사용할 수 있습니다. 7층도 스킬을 선택한 뒤 보물상자와 최종 포탈을 사용할 수 있습니다.

1~3층도 같은 선택 화면으로 통일했습니다. 상세는 BOSS_SKILL_CHOICE.md를 참고하세요. 불씨 파동, 이전 모든 보스 스킬, 장비, 성장, 현재 HP를 보존합니다. 4~7층은 각 층별 보상 슬롯에 저장해 앞선 선택을 덮어쓰지 않습니다. 새 모험/같은 시드 재도전 시에는 모든 보스 스킬이 다시 잠기는 기존 규칙을 따릅니다.

| 보스 | 기본 키 | 선택 1 | 선택 2 |
|---|---|---|---|
| 4 바르칸 | Y | 심장 파쇄: 전방 5×높이 3 충격파, 마력 ×4, 8초 | 왕관 톱니: 13칸 관통 투사체, 마력 ×3.5, 7초 |
| 5 리세아 | U | 거울 파편: 세 방향 관통 탄, 각각 마력 ×1.6, 7초 | 거울 장막: 4초간 피해 35+마력 ×0.5 흡수, 12초 |
| 6 녹티스 | O | 초승달 쌍날: 좌우 12칸 관통 날, 각각 마력 ×3.2, 8초 | 밤의 장막: 반경 3.5에 마력 ×2 피해+4초간 피해 40% 감소, 12초 |
| 7 솔베인 | P | 왕의 광창: 전방 18×높이 3 즉시 관통, 마력 ×5, 10초 | 태양 왕관: 시전 지점 반경 5, 마력 ×2.2를 즉시/0.6초/1.2초 총 3회, 12초 |

각 층의 스킬은 별도 재사용 대기시간을 가집니다. 장비의 마법 재사용 감소를 적용합니다. 0.2초 공통 시전, 기존 후딜레이, 구르기 취소 규칙을 공유하며 한 번에 하나만 시전합니다. 받는 피해는 방어력 처리 → 밤의 장막 감소 → 거울 장막 흡수 순서입니다. 완전 흡수에도 기존 피격 무적이 적용됩니다. 보호 효과와 투사체/장판은 방 이동 및 보스 처치 시 정리하며 선택한 스킬 자체는 유지합니다.

입력 우선순위는 기존 F/Q/E/R/T 이후 새 Y/U/O/P입니다. 누를 때 발동하며 홀드로 자동 반복하지 않습니다. 사용자 지정 키가 신규 기본 키와 겹치면 기존 배정을 우선하고 신규 슬롯은 빈 키를 배정합니다. 설정에서는 14개 동작 전체에 중복 키를 거부합니다. Ctrl/Alt/Shift 좌우는 동일 키로 취급하며 Esc/I/위·아래 방향키/Space는 전용 기능용으로 예약했습니다. 기존 저장된 설정에 예약 키가 있으면 해당 동작에 사용할 수 있는 키로 보정합니다.

하단을 12개 슬롯(이동 버튼 별도)으로 정리하여 기존 8개 버튼과 새 4개를 함께 표시합니다. 각 슬롯에 잠김 상태, 실제 설정 키, 쿨다운, 시전 상태와 문장을 표시합니다. 키 설정 목록도 14행이 화면 안에 들어오도록 간격을 조정했습니다. 획득 알림과 결과 화면에는 새 스킬 이름도 표시합니다. 새 그림 파일 없이 기존 고딕 도형 효과를 확장했습니다.
