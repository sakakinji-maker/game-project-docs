# 문 앞에서 ↑로 이동 (2026-10-28)

- 마을: 성문 중심 X=1120에서 75px 이내에 있을 때 ↑를 새로 누르면 숲으로 출발합니다. 멀리서 누를 수 있던 전역 출발 버튼은 제거했습니다.
- 전투방: 적을 전부 처치한 뒤 문 X=61에서 1.6 월드 단위 이내, 지상에 서 있는 상태에서 ↑를 새로 눌러야 다음 방으로 이동합니다.
- 보스 처치 후 귀환문도 같은 조건으로 사용하며, 기존 완료 화면을 표시합니다.
- 문에 닿거나 문을 지나기만 해서는 이동하지 않습니다. 잠긴 문, 공중, 문에서 먼 위치, 사망 상태에서는 사용할 수 없습니다.
- 키를 누른 순간의 입력만 고정 스텝으로 전달하며 처리 후 소비합니다. 방 전환·일시정지 시 남은 입력도 초기화합니다.
- 마을 대화·설정·일시정지 중에는 출발할 수 없습니다. Space NPC 대화와 ↓+점프 기능은 유지합니다.
- 터치에서는 사용 가능한 문 가까이에 있을 때만 전용 이동 버튼이 표시됩니다.
- 안내 문구, 아린의 설명, 보스 처치 안내와 HUD에 ↑ 조작을 반영했습니다.
