# 화면 표현 수정 — 2026-11-02

- 실제 스킬 이펙트: 기존 SkillIcons는 UI용 그림뿐이었고 전투에서는 Box/선/다각형을 그렸다. 투명 VFX 아틀라스를 추가하고 불씨 파동, 잿불 창, 홍염 고리, 사슬 2종, 태양 2종, 4~7층 보상 8종 전체를 연결했다. 시전 불꽃·진행 방향·사슬 길이·범위·보호막 지속·잔상 페이드에 기존 게임 상태를 사용하며 피해/쿨타임은 바꾸지 않는다.
- 공중 베기: 이전 0.18은 작다는 본인 피드백에 따라 0.21로 조정했다. 8개 프레임 모두 고정 배율, 골반의 가상 기준 높이 41px 보정 유지. 지상 공격 배율은 동일하다. 최종 체감 크기는 본인 QA 대상이다.
- 표시 영역: 실제 화면의 View에 최상위 GUI 클리핑을 적용한다. 화면 비율/레터박스 바깥에 몬스터와 이펙트가 그려지지 않도록 하고 기존 월드/HUD 분리를 유지한다.
- 일반 몬스터: 현재 카메라의 보이는 전투 영역을 Core에 전달한다. 화면 밖 일반 몬스터는 접근하거나 공격을 준비하지 않으며, 화면 밖으로 나간 궁수의 진행 중 준비 동작도 취소한다. 화면 안에 들어오면 재개한다. 방 전체의 배치와 처치 필요 수는 유지하고, 보스의 전용 패턴 이동 범위는 그대로 둔다. 모든 층에 공통 적용한다.
- 보스 대화: Boss 발화는 별도 경로로 분리해 1~7층 해당 스프라이트의 첫 자세를 초상화로 사용한다. 원본 비율로 패널 안에 맞춰 날개/무기가 넘치지 않도록 한다. 로드 대기 시에도 하늘 그림으로 바꾸지 않는다. 내레이션/어머니 기억의 하늘 그림은 유지한다.
- 장비: 5종 전용 그림을 인벤토리 목록, 장착 중 슬롯, 상점, 강화, 상자 획득 안내에 공통 적용한다. 아이템 보유/강화/저장 데이터는 바꾸지 않는다.
