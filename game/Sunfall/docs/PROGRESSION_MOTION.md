# 일반 전투 → 보스전 진행 및 움직임 보간 (2026-10-26)

## 진행 수정

마을 → 숲 전투 맵 → 근접병·궁수·중갑병 각 2마리(총 6마리) 처치 → 오른쪽 성소 진입문 → 공중 성소 비행 보스 → 보스 처치 후 귀환문.

- 런 시작은 `RunStage.Approach`이며 보스는 아직 생성하지 않습니다.
- 일반 적이 한 마리라도 살아 있으면 성소 문이 잠깁니다. 주인공 X를 문 앞에서 제한하여 점프·구르기로도 우회할 수 없습니다.
- 모두 처치해도 즉시 이동하지 않습니다. 열린 문(X=61)에 지상으로 접근해야 `BossArena`로 전환됩니다.
- 첫 맵은 가로 64 단위, 발판 6개와 숲 배경입니다. 궁수는 접근 가능한 높이 3.2 발판 위에 있습니다.
- 보스 맵은 기존 가로 64 단위 공중 성소와 발판 8개를 유지합니다. 비행·돌진·마법탄·2페이즈는 유지합니다.
- 전환 시 남은 HP·최대 HP·공격력·누적 처치 수를 유지하고, 위치·행동·쿨다운·투사체·카메라·시각 보간 기록을 초기화합니다. 입구에서 기존 1초 피격 무적을 적용합니다. 자동 회복이나 증강은 없습니다.
- HUD와 문에는 남은 몬스터 수를 표시합니다. 마을 출발 버튼과 안내도 숲 전투를 먼저 설명합니다.

## 움직임

`SunfallGame.Motion.cs`에서 60Hz 전투 계산과 화면 표시를 분리했습니다.

- 고정 스텝 직전의 위치를 저장하고, 남은 누적 시간 비율로 이전·현재 위치 사이를 보간합니다.
- 주인공, 일반 악마, 비행 보스, 불씨 파동, 화살, 붉은 마법탄에 같은 방식을 적용합니다.
- 카메라는 고정 스텝마다 갱신하던 방식에서 `LateUpdate`의 화면 프레임 단위 추적으로 바꿨습니다.
- 캐릭터 자세는 루트 기준점을 맞춰 짧게 교차 전환합니다. 주인공 기본 65ms, 일반 적 75ms, 보스 날갯짓 100ms. 공격·구르기·돌진은 25ms로 제한합니다.
- 방향을 바꾸면 이전 방향 자세를 버려 반대쪽 검·몸이 남지 않게 합니다.
- 마을 주인공은 기존 프레임별 이동을 유지하고 자세 전환을 적용합니다. 아린의 연속적인 상하 움직임도 일시정지에 맞춰 멈춥니다.
- PC 목표 프레임을 120, 모바일은 60으로 설정합니다. 실제 표시 속도는 VSync·모니터·기기 성능에 따라 달라집니다.
- 전투 판정과 이동 속도는 기존 고정 스텝 기준입니다. 표시 위치 보간에는 최대 한 스텝(약 16.7ms)의 시각 지연이 있습니다.

새 중간 동작 도트를 제작한 것은 아닙니다. 기존 시트의 프레임 수와 픽셀 필터를 유지하면서 위치와 자세 전환의 끊김을 완화했습니다. 짧은 교차 전환 구간에는 두 자세가 함께 보일 수 있으므로 실제 게임에서의 인상은 사용자 QA로 확인해야 합니다.
