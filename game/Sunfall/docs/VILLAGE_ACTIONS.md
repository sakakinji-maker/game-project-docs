# 마을 점프와 스킬 · 2026-11-02

마을에서 전투와 같은 점프 물리·시전 모션·스킬 이펙트·재사용 대기시간을 사용합니다.

- 기본 점프 키 Alt, 스킬 슬롯 F/Q/E/R. 변경한 키 설정도 적용됩니다. Space는 NPC 대화·거래 전용입니다.
- 처음 시작할 때는 불씨 파동만 보유합니다. 모험에서 마을로 돌아오면 해당 모험에서 획득한 스킬과 장착 4칸을 마을 연습용 상태로 복사합니다.
- 마을에서 K 또는 스킬 버튼으로 설명·쿨타임 확인 및 장착/해제를 할 수 있습니다.
- 새 모험은 기존과 같이 기본 스킬부터 시작합니다. 보스 스킬을 영구 해금하거나 저장 규칙을 변경하지 않습니다.
- 화면 조작 버튼을 켜면 이동·점프·스킬을 터치할 수 있습니다. 마을 출발/대화 버튼은 스킬과 겹치지 않는 왼쪽 아래에 배치했습니다.
- NPC 대화와 출발은 지상에서 시전을 마친 뒤 가능합니다. NPC는 전투 시뮬레이션의 적 목록에 들어가지 않으므로 피해를 받지 않습니다.
- 대화·상점·인벤토리·스킬창·설정·일시정지 중에는 물리/쿨타임/이펙트 시간이 정지합니다.
- 마을 카메라는 고정하고 기존 위치 보간을 사용합니다. 점프 높이와 시전 방향·도트 배율은 전투와 같습니다.

## 구현

RunModel.CreateVillagePractice가 적과 발판이 없는 마을용 상태를 만듭니다. 실제 Step으로 이동/점프/마법만 처리하며, 경계는 마을의 110~1170px에 맞춥니다. 전투 출구 판정은 비활성화해 방 진행과 보상 발생을 막습니다.

전투와 마을은 DrawPlayerSpellEffects를 공유합니다. 별도 대체 박스나 임시 이펙트를 사용하지 않습니다. 스킬 효과는 마을 화면 안으로 클리핑합니다.

tools/Compile-AttackArt.ps1 -OutputFolder Temp/VillageActionsCompile

Core·Runtime·Editor·Tests 모두 exit=0.
