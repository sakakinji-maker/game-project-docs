# 환경설정 개편 · 2026-11-02

시작 화면과 어울리는 어두운 남색·상아색·금빛 고딕 패널로 전체 환경설정 UI를 변경했습니다. 기존 GUI 도형·선·글꼴을 사용하며 새 래스터 이미지는 추가하지 않았습니다.

## 화면 구성

- 왼쪽 탐색: 조작 / 소리 / 화면 조작 버튼.
- 조작: 9개 키를 두 열의 큰 키 버튼으로 표시. 기본 키 복원과 고정 키 안내.
- 키 변경: 별도 모달 창에 기능 이름, 현재 키, 입력 상태, 중복·예약 키 안내, 취소 버튼 표시. 뒤쪽 UI 입력 차단.
- 소리: 배경 음악 음량 게이지와 퍼센트. 게이지 클릭·터치로 5% 단위 선택, ±5%, 음소거, 최대 음량, 기본 18% 복원.
- 화면 조작 버튼: 켜짐/꺼짐, 배치 안내, 자동 저장. 모바일에서는 항상 표시.
- 하단: 변경 결과와 완료 버튼. Tab/Shift+Tab으로 항목 이동, 소리 화면에서 ←/→ 조절, Esc로 닫기.

## 동작

- 기존 키·음량 저장 키 유지. 화면 버튼 표시는 sunfall.touchPreview에 저장합니다.
- 설정 화면에서는 음악을 메뉴 감쇠 없이 설정한 음량으로 재생하여 조절 결과를 확인할 수 있습니다. 닫으면 기존 일시정지/대화 감쇠 규칙으로 돌아갑니다.
- 키를 변경하는 동안 F10은 예약 키로 거부하며 진행 데이터를 초기화하지 않습니다. 일반 상태의 개발자 F10 초기화는 유지합니다.
- 게임 진행, 기존 스토리 시청 기록과 기존 키 배정은 초기화하지 않습니다.
- 화면 크기와 입력은 기존 1280×720 논리 좌표 및 안전 영역 변환을 사용합니다.
