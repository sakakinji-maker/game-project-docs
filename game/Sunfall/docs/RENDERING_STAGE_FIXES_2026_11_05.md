# 2026-11-05 렌더링·봉합·4~6스테이지 수정

## 반영 내용

- 이미지 좌표를 화면 위치로 변환한 후 중심 회전하도록 공통 렌더링 수정. 주인공·보스 스킬, 사슬, 왕좌, 어머니 포획/하강 이미지의 잘림을 대상으로 반영했습니다.
- 하늘 봉합의 굵은 X자를 가는 곡선 바느질과 잔광으로 변경했습니다.
- 4층 심장 장치와 사슬을 배경의 같은 좌표계로 연결하고 사슬 시작점을 천장 기둥에 고정했습니다.
- 5층 세 번째 전투방에서 x54~61의 추가 발판을 제거했습니다. 기존 x47~56 발판은 유지하고, x61의 출구 앞에 지면으로 내려설 공간을 확보했습니다.
- 5층 보스 거울의 봉합은 내부 반사광, 테두리 빛, 갈라지는 금빛 봉합선으로 확대했습니다.
- 6층 일식은 배경 좌표에 고정하고 본체 150→310, 바깥 효과 최대 470으로 확대했습니다. 화면 전반의 분위기 효과와 장막 공격의 상단 표시도 확장했습니다. 장막의 안전지대 클리핑과 피해 판정은 유지합니다.

## 검증 범위

Unity 6000.3.27f1의 Roslyn 참조로 Core / Runtime / Editor / Tests 어셈블리를 컴파일했으며 모두 exit=0입니다. 마지막 결과: 로컬 `Temp/Stage456SceneFixCompile/compile.log`. 로그와 캐시는 저장소에서 제외합니다.

Play, 자동 테스트 실행, 플레이 QA, EXE 빌드는 수행하지 않았습니다. 시각적 수정은 사용자 QA 확인 전입니다.

## 사용자 QA 확인 항목 (미실행)

1. 좌우 방향의 스킬, 회전 이펙트, 어머니의 포획·하강 이미지가 잘리지 않는지.
2. 4층 3번째 전투방/보스방에서 이동·점프해도 사슬이 천장 기둥에 붙어 있는지.
3. 5층 3번째 전투방 출구 앞에서 지면으로 내려온 뒤 ↑로 보스방에 진입 가능한지.
4. 5층 보스 처치 뒤 거울 봉합이 충분히 보이고 프레임 밖으로 넘치지 않는지.
5. 6층 일식과 장막이 잘 보이면서 발판·캐릭터·초록 안전지대를 가리지 않는지.
