# 스토리 시청 기록 — 2026-11-02

이전에는 골드·장비·성장만 저장했고 스토리는 매 실행마다 재생했다. 이제 `sunfall.story.seen.v1`에 시청 비트 마스크를 저장한다.

- 저장 대상: 서장 1개, 1~7층 보스 등장/처치 대사 14개, 3~7층 진입 대사 5개. 번역 문구와 무관한 고정 ID를 사용한다.
- 마지막까지 진행하거나 건너뛰면 PlayerPrefs.Save로 즉시 저장한다. 서장은 마지막 암전/명시적 건너뛰기 시작에 기록하므로 암전 중 종료해도 유지된다.
- 중간 장면에서 게임을 종료한 경우 완료로 기록하지 않는다.
- 이미 본 서장은 시작 메뉴에서 '마을로 가기'로 표시하고 바로 마을에 진입한다. 새 모험·재실행에도 본 대사는 다시 열지 않는다.
- 보스 등장/처치의 전투 연출·보상은 유지한다. 반복 이용이 필요한 마을 NPC 대화·상점·강화는 시청 기록 대상이 아니다.
- 구버전 저장에 시청 기록이 없고 골드>0, 레벨>1, 경험치>0 또는 보유 장비가 있으면 서장을 본 것으로 최초 1회 이관한다. 과거 개별 보스 대사 시청 여부는 저장돼 있지 않았으므로 추정하지 않는다.
- F10 개발자 초기화에서 시청 마스크도 0으로 저장한다. 키를 삭제하지 않아 기존 진행 데이터로 서장 완료가 다시 복구되지 않는다. 다음 시작은 서장부터다.
- 컴포넌트 OnEnable에서 불러와 재실행 및 Unity 스크립트 리로드에 대응한다.

Core·Runtime·Editor·Tests 컴파일 통과: `Temp/StoryProgressCompile/compile.log`.
실제 앱 재시작, F10 초기화, 플레이·QA·테스트 실행은 하지 않았다.
