# 스킬 애니메이션과 시작 화면 복원 — 2026-11-02

## 시작 화면

사용자가 첫 진입 화면부터 깨진다고 확인했다. 직전 변경에서 추가한 물리 화면 좌표의 최상위 GUI 그룹을 제거하고, 기존의 논리 캔버스(1280×720) → View 이동/크기 변환 하나로 복원했다. 포인터의 Point 변환과 같은 기준을 쓴다. 화면 바깥 출력은 마지막에 레터박스 영역을 검게 덮는 방식으로 처리한다. 기존 월드 영역 그룹과 HUD 분리는 유지한다.

실제 화면 복구 여부는 사용자 QA 대상이며, 이번 작업에서 플레이로 확인하지 않았다.

## 애니메이션

- 불씨 파동: 서로 다른 불꽃 윤곽 8프레임, 초당 16프레임 루프. 새 프레임의 밝은 중심을 기준으로 정렬해 상·하단 행 전환의 위치 튐을 보정했다. 후류 불꽃과 흩어지는 불씨를 더했다.
- 잿불 창: 창 몸체 위로 위상이 다른 불꽃 3개와 뒤로 흐르는 불씨를 겹친다.
- 포박 사슬: 각 금속 마디를 연결해 발사 0.075초 동안 뻗고 휘어진 선이 팽팽해진다. 고리는 끝점을 따라 회전한다. 잡힌 대상의 보간 위치를 따라 당긴다.
- 사슬 강림: 마디가 아래로 떨어지고 충격 불꽃과 함께 위로 반동한다. 7줄의 미세한 위상 차이를 적용한다. 피해는 기존 시전 완료 시점 그대로이며 즉시 충격 불꽃으로 표시한다.
- 홍염 고리: 회전하는 고리에 독립 위상 불꽃 12개를 배치한다.
- 태양/왕실 광창: 광창을 따라 흐르는 빛 입자. 여명의 폭발·거울 장막·밤의 장막·태양 왕관·심장 파쇄에는 회전/확산 입자.
- 거울 파편·초승달 쌍날: 흔들리는 잔상과 꼬리 입자. 왕관 톱니는 기존 회전에 입자를 추가했다.
- 시전: 손으로 모여드는 불씨와 회전하는 불꽃 문장.

피해·범위·쿨타임·획득·장착 로직은 변경하지 않는다. 애니메이션은 visualClock만 읽으며 OnGUI에서 시간을 누적하거나 게임 난수를 소비하지 않는다. 메뉴/대화/일시정지 중 정지한다. 사슬은 줄마다 최대 48마디, 입자는 고정 개수라 실행 시간에 따라 객체가 쌓이지 않는다.
