# 코드 점검 및 수정 — 2026-11-02

플레이를 실행하지 않고 최근 변경 경로와 기존 UI/공중 공격 상태 전이를 읽어 확인한 문제를 수정했다.

## 수정 내용

1. 공중 공격 후 착지해도 AirAttack/AttackStage가 남았다. 이후 점프 입력 없이 발판에서 걸어 내려가면 이전 공중 공격 회수 자세를 다시 선택할 수 있었다. 착지 상태에서 공격이 끝난 경우에만 정리한다. 착지 순간 진행 중인 타격은 취소하지 않는다.
2. 공중 공격 회수 프레임은 계속 선택하면서 방향은 이동 방향으로 바뀌었다. 공통 AirSwordRecovery 조건으로 자세 선택과 ActionFacing을 맞췄다.
3. 스킬 슬롯 그림은 y=710까지 표시하지만 터치는 y=674에서 끝났다. 제목·키·쿨타임 막대·상태 문구까지 포함하도록 높이를 늘렸다. 문/상자 터치 버튼은 첫 스킬 슬롯과 겹치지 않게 왼쪽으로 옮겼다.
4. 미니맵 x=838~1072 위에 스킬창 버튼 x=925~1080이 겹쳤다. 전투 중 스킬/인벤토리 버튼은 오른쪽 설정 버튼 아래에 세로로 배치했다. 마을 인벤토리 위치는 유지한다.
5. Block()의 짧은 입력/시뮬레이션 대기 중 visualClock과 카메라가 계속 진행했다. 같은 대기 조건을 LateUpdate에도 적용해 메뉴를 닫은 직후 이펙트만 먼저 움직이지 않도록 했다.
6. GothicPlaque가 높이 전체를 매번 다각형 스캔라인으로 그렸다. 사각 중앙부를 1회 그리고 모서리만 스캔한다. 예를 들어 높이 660, 모서리 18인 패널은 660줄 대신 37회다. 가운데/모서리의 영역을 겹치지 않게 나눠 반투명 패널 밝기를 유지한다. 실제 프레임 속도는 측정하지 않았다.
