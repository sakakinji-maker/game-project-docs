# 2스테이지 사슬 스킬 보상

모르가 처치 확정 시 포박 사슬 / 사슬 강림 중 하나를 각각 50%의 시드 기반 확률로 자동 획득합니다. 상자와 별도이며 한 모험에서 한 번만 추첨합니다. 1스테이지 보상은 별도 필드에 보존하므로 잿불 창(Q) 또는 홍염 고리(E)를 그대로 사용할 수 있습니다. 기본 불씨 파동(F)도 유지합니다.

| 스킬 | 효과 | 재사용 |
|---|---|---|
| 포박 사슬 | 전방 8 범위, 시전 높이의 가장 가까운 적 1명에게 마력 150% 피해. 일반 적을 0.28초에 걸쳐 앞쪽 1.4 지점으로 끌어옵니다. 기존 공격을 끊고 0.6초간 다음 공격을 늦춥니다. 보스는 피해만 받고 위치/공격을 유지합니다. | 6초 |
| 사슬 강림 | 시전 위치 양옆 4, 발아래 0.4부터 위쪽 4까지 사슬을 내려 마력 280% 피해를 한 번 줍니다. | 9초 |

공통: 시전 0.2초, 후딜 0.18초, 지상/공중 사용, 시전 중 구르기로 취소 가능. 성소의 인장 재사용 감소와 마력 성장·장비를 적용합니다. 사슬 효과는 금빛 고리로 표시해 보스의 붉은 공격과 구분합니다. 포박 사슬에 끌린 일반 적은 목적지의 발판 또는 지면에 착지하고 순찰 범위를 그 바닥에 맞춥니다.

## 조작과 수명

- 두 후보 중 획득한 하나를 별도 **R** 키와 사슬 슬롯으로 사용합니다. 새 슬롯은 기존 Q/E/F 및 구르기·검·점프와 분리되어 있습니다.
- 설정에 아홉 번째 '사슬 스킬' 항목을 추가했습니다. 기존 저장 설정에서 R이 이미 다른 동작에 배정되었다면 기존 설정을 우선하고 사슬에는 사용하지 않는 대체 키를 지정합니다. HUD와 획득 안내는 실제 설정 키를 표시합니다. 키 재지정 시 중복 키를 거절합니다.
- 터치에서도 독립 사슬 버튼을 사용합니다. 문/상자 버튼과 이동 버튼 영역이 겹치지 않도록 배치를 조정했습니다.
- 미획득 상태에서는 2탄 보스 보상으로 잠김 표시하며 입력해도 시전/효과/쿨다운을 만들지 않습니다.
- 처치 연출과 획득 안내에 새 사슬 스킬을 표시하고, 완료 화면에 1·2스테이지 보상 스킬을 함께 표시합니다.
- 두 보상 모두 현재 모험에 유지됩니다. 새 모험/같은 시드 재도전은 다시 잠김으로 시작합니다. 영구 장비/골드/성장 저장은 그대로입니다.
- 2스테이지 보스 뒤 포탈은 3스테이지 왕도 대성당으로 이어집니다. 같은 모험을 유지하므로 사슬 스킬과 1스테이지 보상 스킬을 모두 대성당에서도 사용할 수 있습니다. 상세: CHAPTER_THREE.md.
