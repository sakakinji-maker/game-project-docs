# 3스테이지 — 왕도 대성당

## 이동과 유지 상태

모르가를 처치한 뒤 연출·대사가 끝나면 열린 포탈 앞에서 ↑를 눌러 3스테이지 첫 방으로 이동합니다. 처치 전, 연출 중, 공중에서는 이동하지 않습니다. 상자를 열지 않아도 이동할 수 있으나 미개봉 상자의 물약/장비를 자동 지급하지 않습니다. 스킬은 보스 처치 때 이미 획득하므로 상자와 무관하게 유지합니다.

새 모험을 만들지 않고 기존 RunModel의 Chapter를 3으로 바꿉니다. 현재 HP·최대 HP·장비 소유/장착/강화·골드·경험치·성장·처치 수·시드를 보존합니다. 불씨 파동, 1보스의 잿불 창 또는 홍염 고리, 2보스의 포박 사슬 또는 사슬 강림을 모두 그대로 사용할 수 있습니다. 기존 입력 F/Q/E/R과 사용자가 바꾼 키도 유지됩니다. 얻지 않은 다른 후보 스킬은 계속 잠겨 있습니다.

방 진입 위치는 X=2, Y=0입니다. 이전 적/투사체/사슬/구속/시전/효과/쿨다운/보물상자/보스 연출 상태를 초기화하고 카메라와 보간·입력 큐를 정리합니다. 기존 방 이동 규칙대로 진입 무적 1초를 적용하며 HP는 자동 회복하지 않습니다. 마을 귀환이나 사망 후 새 모험/같은 시드 재도전은 기존대로 1스테이지에서 시작하고 보상 스킬을 다시 잠급니다.

## 전투방

| 방 | 적 배치 | 발판 (시작 X, 너비, 높이) |
|---|---|---|
| 대성당 진입로 | 근접 3 / 궁수 2 / 중갑 2 = 7 | (8,8,1.6), (13,8,3.2), (27,10,1.6), (41,8,1.6), (46,8,3.2) |
| 왕실 회랑 | 근접 3 / 궁수 3 / 중갑 2 = 8 | (7,8,1.6), (12,9,3.2), (26,10,1.6), (40,8,1.6), (45,10,3.2) |
| 태양 봉인 예배당 | 근접 4 / 궁수 2 / 중갑 3 = 9 | (7,8,1.6), (12,8,3.2), (17,8,4.8), (39,8,4.8), (44,8,3.2), (49,8,1.6) |

각 방 가로 64, 출구 X=61. 1.6 높이의 계단식 발판은 기본 점프로 올라갈 수 있게 겹쳤습니다. 상층 적 순찰 범위는 지지 발판 안으로 제한합니다. 적 HP는 원래 수치의 1.4배(근접 61.6 / 궁수 50.4 / 중갑 140), 공격과 골드/경험치 규칙은 기존대로입니다. 지상 적은 사슬 끌어오기와 광역 스킬을 활용할 수 있도록 묶어서 배치했습니다.

모든 적을 잡아야 각 출구가 열리며 접촉만으로 이동하지 않습니다. 예배당도 전원 처치 후 지상 출구 앞 ↑로 네 번째 방인 태양 봉인의 내전에 진입합니다. 아우렐(HP 600)을 처치해야 4스테이지 왕관의 심장부로 가는 포탈이 열립니다. 상세: STAGE3_SOLAR_REGENT.md. 봉인 외곽을 해방한 뒤 모든 획득 스킬과 현재 상태를 유지해 4스테이지로 진행합니다(CHAPTER_FOUR.md). 최종 구출 결말은 아직 구현하지 않았습니다.

## 미술과 대사

기존 먼 배경 위에 코드로 고딕 석조 기둥, 첨두 스테인드글라스 창문, 붉은 왕실 깃발, 금빛 장식을 추가했습니다. 대성당 발판은 풀 대신 석조 표면과 벽돌 줄눈을 그립니다. 예배당 중앙에는 사슬에 묶인 어두운 태양 문장이 보입니다. 장식은 충돌하지 않으며 발판과 구분됩니다. 신규 외부 이미지 생성은 하지 않았습니다.

모르가 처치 마지막 대사를 포탈을 통한 왕도행으로 수정하고, 3스테이지 최초 진입 대사 3쪽을 연결했습니다. Space/다음 버튼으로 진행하며 대화 중 전투가 정지합니다. HUD, 방 이름, 목적지 표지, 보스 처치 안내, 완료 문구를 새 진행에 맞췄습니다.
