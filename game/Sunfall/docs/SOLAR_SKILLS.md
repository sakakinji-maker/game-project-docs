# 3스테이지 태양 스킬 보상

아우렐 처치가 확정될 때 **태양의 창 / 여명의 폭발 중 하나**를 각각 50%의 시드 기반 확률로 자동 획득합니다. 상자 개봉과 무관하며 같은 처치로 다시 추첨하지 않습니다. 기존 불씨 파동과 1보스 보상, 2보스 사슬 보상은 각각 별도 상태로 유지합니다.

| 스킬 | 효과 | 기본 재사용 |
|---|---|---|
| 태양의 창 | 전방 14 범위, 속도 26의 금빛 투사체. 관통하며 각 적에게 마력 400% 피해를 한 번 줍니다. 이동 구간 전체를 검사해 빠른 투사체가 적을 건너뛰지 않게 합니다. | 8초 |
| 여명의 폭발 | 시전자 위치에서 높이 +1을 중심으로 반경 4.5에 마력 320% 피해를 한 번 줍니다. 원과 적 몸체가 겹치는지 판정해 양옆·공중 적을 함께 공격합니다. | 10초 |

두 마법 모두 지상/공중 시전, 시전 0.2초와 후딜 0.18초를 사용합니다. 시전 중 구르기로 취소할 수 있고, 취소하면 효과와 쿨다운이 발생하지 않습니다. 마력 성장과 장비 피해 배율, 성소의 인장 재사용 감소를 적용합니다. 기존 스킬과 태양 스킬의 쿨다운은 독립적입니다.

## 입력과 표시

- 획득한 하나를 별도 **T 키**로 사용합니다. F 불씨 파동 / Q·E 1보스 보상 / R 사슬 스킬은 기존 키를 유지합니다.
- 조작 설정의 열 번째 항목은 '태양 스킬'입니다. 이전 저장 설정에 T가 사용 중이면 기존 동작을 우선 보존하고 새 항목에 사용하지 않는 키를 배정합니다. 실제 키는 HUD와 획득 안내에 표시합니다. 재지정 때도 다른 동작과 중복되는 키를 거절합니다.
- HUD에 태양 문장 슬롯과 터치 버튼을 추가했습니다. 미획득 시 '3탄 보스 보상'으로 잠기며, 키를 눌러도 시전·투사체·쿨다운을 만들지 않습니다.
- 새 슬롯을 위해 PC 안내 폭을 줄이고 터치 문/상자 버튼을 하단 빈 공간으로 옮겼습니다. 설정의 음량/안내도 마지막 키 행과 겹치지 않게 내렸습니다.
- 처치 연출과 획득 안내에 새 스킬 이름을 표시하고, 결과 화면에는 1·2·3보스 보상을 함께 표시합니다.
- 태양의 창은 금빛 창과 태양 문장으로, 여명의 폭발은 고정된 피해 반경의 금빛 테두리와 빛줄기로 그립니다. 게임 코드로 만든 효과이며 새 외부 이미지를 생성하지 않았습니다.

## 유지 범위

세 보상은 현재 모험에 유지됩니다. 새 모험/같은 시드 재도전은 보상 스킬을 다시 잠급니다. 영구 장비·골드·성장 저장은 바꾸지 않습니다. 3보스 처치 연출 후 내전에서 태양 스킬을 사용할 수 있으며, 포탈은 4스테이지 왕관의 심장부로 이어집니다. 같은 모험을 유지하므로 모든 획득 스킬을 4스테이지에서도 사용할 수 있습니다. 상세: CHAPTER_FOUR.md.

Core / Runtime / Editor / Tests / 독립 CoreChecks 컴파일만 확인했습니다. 로그: `Temp/SolarSkillsCompile/compile.log`.

태양 보상 두 경우의 획득·시드 재현·중복 방지, 세 보상과 기본 마법의 독립 시전, 새 모험 초기화, 잠금 입력 무시, 구르기 취소, 관통 단일 타격과 높이/거리, 원형 범위와 단일 타격, 장비 쿨다운 감소를 검사하는 테스트 코드를 추가했습니다. 사용자 요청대로 테스트 실행·Unity Play·게임 QA·플레이어 빌드는 수행하지 않았습니다.
