# 고정 서장 화면과 개발자 초기화

2026-11-01.

## 서장 화면 고정

`DrawOpeningCinematic`에서 시간에 따른 좌우 이동, 확대, 중첩 GUI 그룹/행렬 변환을 제거했습니다. 배경은 항상 동일한 1280×720 영역에 그립니다. 자막·페이드·사슬·입자·별실은 기존 장면 시계에 따라 동작합니다. 화면 크기 변화에 대한 기존 safe-area 스케일만 사용합니다.

## F10 개발자 초기화

Unity 에디터 또는 Development Build에서 F10을 누르면 확인창 없이 즉시 초기화합니다. 일반 배포 빌드에서는 작동하지 않습니다. 시작 화면 상단에 `DEV · F10 진행 데이터 초기화`가 표시됩니다.

- 저장된 골드 0, 레벨 1, 경험치 0, 능력치 배분 0, 기본 성장 포인트 2.
- 장비 보유·장착·강화 초기화.
- 현재 모험, 보스 스킬, 스킬 장착, 전투/스토리/시네마틱 진행 종료.
- 열린 UI, 일시정지, 키 변경 대기, 입력 큐, 이동 보간 상태를 정리하고 시작 화면으로 복귀.
- 다음 테스트 모험의 시드는 재현 가능하도록 초기 시드 12345에서 시작하며 기존 StartRun의 증가 규칙을 사용.
- 키 설정과 음량은 유지. PlayerPrefs.DeleteAll이나 저장 폴더 삭제를 사용하지 않습니다. 기존 SaveEquipment를 통해 진행 데이터 기본값만 저장합니다.
- F10은 재지정 불가한 전용 키입니다. 예전에 F10으로 저장했던 동작은 Bindings의 기존 유효성 검사와 대체 키 처리에 따라 복구됩니다.
- 타이틀·서장·마을·전투·일시정지·설정/키 변경 대기에서 동일하게 처리됩니다. 누른 첫 프레임에 한 번만 실행합니다.

보스 처치 및 기존 자동 저장 정책은 변경하지 않았습니다.

구현: `Runtime/SunfallGame.Developer.cs`, `SunfallGame.cs`, `Bindings.cs`, `SunfallGame.Title.cs`, `SunfallGame.OpeningCinematic.cs`.

컴파일 로그: `Temp/StableOpeningDeveloperResetCompile/compile.log`. Unity Play, 게임 QA, 테스트 및 F10 초기화를 실제로 실행하지 않았습니다. 작업 중 사용자의 저장 데이터는 변경하지 않았습니다.
