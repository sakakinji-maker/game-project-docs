# 공격 중간 프레임 적용 (2026-10-26)

주인공과 악마의 기존 디자인을 참조하여 built-in image_gen 도구로 실제 중간 자세를 새로 그렸다. 선택한 투명 PNG를 프로젝트 Resources 안에 저장했으며 기존 아트는 보관했다.

## 적용한 시퀀스

| 대상 | 시퀀스 | 새 시트 |
|---|---|---|
| 주인공 | 검 1타 / 2타 / 3타 / 공중 베기 / 불씨 파동 | Hero/Combat/Combo1V3, Combo2V3, Combo3V3, AirSlashV3, EmberCastV3 |
| 일반 악마 | 근접 도끼 / 궁수 발사 / 중갑 내려찍기 | Demons/MeleeAttackV2, ArcherAttackV2, HeavyAttackV2 |
| 보스 | 비행 돌진 / 붉은 마법탄 / 지면 파동 | Demons/BossDashV2, BossBoltsV2, BossWaveV2 |

각 시트는 1024×1536 RGBA, 2열×4행의 실제 도트 8장이다. 총 11개 시트, 88개 자세. 경로는 모두 `Assets/Sunfall/Resources/` 기준.

## 재생과 정렬

- 후속 크기 수정: V3 공격 도트의 해부학적 크기가 기본 대기/이동 도트보다 커 보이는 문제를 보정했다. 지상 공격에는 기존 표시 배율에 0.8을 적용한다(1타 0.24, 2타/3타 0.224, 마법 0.204). 2026-11-02 공중 베기는 머리와 몸통이 여전히 크게 보이는 점을 반영해 별도 보정 0.6(배율 0.18)을 적용했다가 작다는 본인 피드백에 따라 최종 보정 0.7(배율 0.21)로 재조정했다. 준비부터 회수까지 8개 프레임 모두 같은 배율을 사용하며, 웅크림이나 검 궤적 크기에 따라 자동 확대하지 않는다. 공중 베기는 가상 기준점을 역보정해 골반 높이 41px를 유지하며, 지상은 기존 발바닥 기준점을 유지한다. 원본 PNG와 공격 판정은 변경하지 않았다. Core·Runtime·Editor·Tests 컴파일 통과: `Temp/AirAttackScaleCompile/compile.log`. 플레이·QA·테스트 실행 없음.
- 준비 자세 0~2, 실제 타격/발사 프레임 3, 후속 동작과 회수 4~7.
- 검격은 시뮬레이션의 실제 준비 잔여 시간과 발동 시 남은 회수 시간에 맞춰 진행한다. 콤보 시작의 첫 준비 프레임은 이전 타격의 마지막 프레임을 사용하여 연결한다.
- 불씨 파동은 기존 준비 0.2초, 회수 0.18초 동안 8장을 재생한다.
- 일반 적은 기존 Windup/AttackPose 시간을 사용한다. 보스는 돌진 준비 0~2 → 비행 중 3~4 → 제동 5~7, 마법은 준비 0~2 → 발사/회수 3~7.
- 2페이즈 각성에는 파동의 준비 자세를 사용하며 가짜 공격 발동 프레임을 표시하지 않는다.
- 공격 내부는 도트 프레임을 직접 교체해 이중 실루엣을 피한다. 이동 위치 보간과 대기/이동 전환 블렌딩은 유지한다.
- 원본 PNG의 실제 알파 영역을 측정한 개별 UV를 사용한다. 수학적인 2×4 등분선을 넘는 검이나 활도 각 프레임의 전체 실루엣을 포함한다. 궁수 첫 행 오른쪽 발과 둘째 행 활 끝은 서로 매우 가까우므로 정확한 개별 경계를 사용한다.
- 지상은 골반의 X와 발바닥의 Y, 공중/보스는 골반과 가상 몸체 기준점으로 정렬했다. 새 데이터: `Runtime/SunfallGame.AttackArt.cs`.
- 피해량, 판정 범위, 공격 속도, 쿨다운, 몬스터 처치 후 보스 진입 조건은 유지한다. Core에 추가한 시간 정보는 표시용이다.
- Texture2D, Point, Clamp, 원본 알파, 무압축, mipmap off. 기존 아트/새 공격 시트가 임포트 중이면 재시도한다.

## 확인 범위

Unity 6000.3.27f1에 포함된 Roslyn과 현재 Bee 응답 파일/참조를 사용해 Core, Runtime, Editor, Tests 어셈블리 **컴파일만 성공**했다. 컴파일러 오류/경고 출력 없음.
로그: `Temp/AttackFramesCompile/compile.log`.
Unity 에디터 Play, 게임 실행, 테스트 실행, 인게임 QA는 수행하지 않았다. 실제 재생 인상과 타격감은 본인 QA 대상이다.

작업 도구는 프로젝트 상위 `tools/`의 Compile-AttackArt.ps1, Measure-AttackArt.ps1, attack-art-layout.json, attack-art-bounds.json. Measure는 PNG 픽셀을 변경하지 않고 알파 영역을 읽고 원본을 복사한다.
