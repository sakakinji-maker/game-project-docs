# 스킬창과 4칸 장착

모험 중 **K** 또는 상단 **스킬 (K)** 버튼으로 열고, K/Esc/닫기 버튼으로 닫습니다. 스킬창이 열린 동안 전투·이동·연출 시간·쿨타임은 멈춥니다. 인벤토리·대화·보스 연출·보상 선택 화면과 겹쳐 열리지 않습니다. 모험 결과에서는 K로 열람할 수 있지만 변경할 수 없습니다. 마을 귀환은 기존처럼 모험을 종료하므로 모험 스킬 목록도 종료됩니다.

1. 왼쪽 획득 목록에서 스킬을 고릅니다. 최대 8종(불씨 파동 + 보스별 1종)을 표시합니다.
2. 오른쪽에서 효과 설명, 기본 쿨타임, 장비 효과를 적용한 쿨타임, 현재 남은 쿨타임을 확인합니다.
3. 장착할 1~4번 칸을 누릅니다. 이미 장착된 스킬을 다른 칸에 넣으면 두 칸을 교환합니다.
4. ‘선택 스킬 해제’를 누르면 그 칸이 비며, 획득 목록에는 남습니다.

기본 키는 슬롯 1 F / 슬롯 2 Q / 슬롯 3 E / 슬롯 4 R입니다. 설정에는 ‘스킬 슬롯 1~4’로 표시합니다. 이전 설정의 F/Q/E/R에 대응하는 동작 인덱스 5~8의 사용자 키를 유지하며, 스킬마다 지정하던 T/Y/U/O/P 입력은 사용하지 않습니다. K는 스킬창 전용 키로 예약하고 중복/예약 키는 기존 로더 규칙으로 빈 키에 보정합니다. 하단 HUD에는 현재 장착 스킬 네 개, 빈 칸, 실제 지정 키와 각 쿨타임을 표시합니다. 같은 네 칸으로 터치 조작도 가능합니다.

불씨 파동을 포함해 최대 4개입니다. 새 모험은 불씨 파동만 1번 칸에 장착합니다. 보스 스킬을 획득하면 빈 칸이 있을 때만 자동 장착합니다. 네 칸이 이미 차 있으면 기존 구성을 바꾸지 않고 새 스킬을 선택한 상태로 스킬창을 열어 교체 여부를 결정하게 합니다. 창을 닫으면 기존 구성을 그대로 사용합니다. 이미 습득한 스킬과 보스 보상 기록은 장착 상태와 별도로 유지합니다.

장착과 해제는 살아 있고 공격·시전·구르기·보스 연출·보상 선택 중이 아닐 때 가능합니다. 전투 중에도 동작을 마친 상태에서 창을 열어 변경할 수 있습니다. 동작 중 열었다면 설명을 보고 창을 닫은 뒤 동작을 마쳐야 교체할 수 있습니다.

쿨타임은 슬롯이 아니라 스킬에 귀속됩니다. 해제하거나 다른 칸으로 옮겨도 남은 시간이 바뀌지 않습니다. 미장착 스킬도 게임 시간이 흐르면 쿨타임이 줄어들며, 스킬창에서는 시간이 멈춥니다. 같은 스킬을 중복 장착할 수 없고, 습득하지 않은 스킬이나 범위를 벗어난 슬롯 요청은 거부합니다. 기존 스킬별 입력 인자를 통한 우회 호출도 장착 여부를 검사합니다. 구르기 시전 취소와 독립 쿨타임 등 기존 전투 규칙은 유지합니다.

방/층 이동 시 네 칸의 구성과 획득 목록을 유지합니다. 방 이동 시 쿨타임과 진행 중 효과를 정리하는 기존 규칙은 유지했습니다. 새 모험과 재도전은 기존대로 습득 보상을 초기화하고 불씨 파동부터 시작합니다.

## 확인 범위

Core / Runtime / Editor / Tests / 독립 CoreChecks **컴파일만 확인**. 로그: `Temp/SkillLoadoutCompile/compile.log`.

최대 4개 제한, 미습득·잘못된 슬롯 거부, 중복 방지와 슬롯 교환, 습득 목록 보존, 빈 칸 자동 장착, 미장착 입력 차단, 시전 중 변경 거부, 교체/이동 후 쿨타임 유지, 각 슬롯 시전, 방 이동 유지, 새 모험 초기화의 회귀 테스트 코드를 추가했습니다. 기존 후반 스킬 시전 테스트는 먼저 스킬을 장착하도록 수정했습니다. Unity Play·게임 QA·테스트 실행·플레이어 빌드는 수행하지 않았습니다.
