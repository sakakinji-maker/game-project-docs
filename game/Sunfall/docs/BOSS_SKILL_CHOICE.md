# 1~7층 보스 스킬 선택

이제 모든 보스는 처치 시 스킬을 자동 지급하지 않고 선택을 대기합니다. 처치 대사와 소멸 연출이 끝나면 두 후보의 이름, 효과, 기본 재사용 시간과 실제 설정 키를 보여 줍니다. 클릭/터치로 하나를 확정하며, 선택창의 ‘운명에 맡기기’를 눌렀을 때만 두 후보 중 50% 무작위로 획득합니다. 무작위는 기존 시드 기반 생성기를 사용합니다.

| 층 | 후보 1 | 후보 2 | 기본 사용 키 |
|---|---|---|---|
| 1 | 잿불 창 | 홍염 고리 | Q / E 중 선택한 스킬 |
| 2 | 포박 사슬 | 사슬 강림 | R |
| 3 | 태양의 창 | 여명의 폭발 | T |
| 4 | 심장 파쇄 | 왕관 톱니 | Y |
| 5 | 거울 파편 | 거울 장막 | U |
| 6 | 초승달 쌍날 | 밤의 장막 | O |
| 7 | 왕의 광창 | 태양 왕관 | P |

현재 층의 보상만 기록합니다. 불씨 파동과 앞선 모든 선택, 현재 HP, 장비, 성장과 사용자 키 설정은 유지합니다. 한 번 확정하면 다른 후보를 고르거나 다시 추첨할 수 없습니다. 이미 기록된 보상을 덮어쓰지 않습니다. 신규 키나 피해/쿨다운 변경은 없습니다. 새 모험에서는 기존 규칙대로 보스 스킬을 다시 획득합니다.

연출 중에는 선택할 수 없고, 선택 대기 중에는 게임 시간이 멈추며 이동/전투/상자/문/장비 변경이 차단됩니다. Esc 일시정지와 설정은 사용할 수 있습니다. 선택을 마치면 획득 안내를 표시하고 상자와 다음 층 이동을 허용합니다. 7층은 선택 후 최종 포탈을 사용할 수 있습니다. 선택 전 소멸 연출에는 획득한 것처럼 스킬 이름을 표시하지 않고 ‘연출이 끝나면 선택’ 안내를 표시합니다.

공통 후보와 설명은 `Core/BossSkillCatalog.cs`, 확정은 `RunModel.ChooseBossSkill`, 선택 화면은 `Runtime/SunfallGame.LateSkills.cs`가 담당합니다. 선택한 스킬은 기존 BossSpellReward / ChainSpellReward / SolarSpellReward / 후반 슬롯을 그대로 사용하여 기존 시전·HUD·결과 안내를 유지합니다.
