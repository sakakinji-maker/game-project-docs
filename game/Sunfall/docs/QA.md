# 첫 프로토타입 QA

## 실행한 핵심 로직 검사

2026-10-26: .NET 8 런타임 + Roslyn 컴파일러로 실제 `RunModel.cs`와 `CoreTests/Program.cs`를 컴파일하고 실행했다. 18개 검사 통과.

동일 시드 적/발판 생성, 점프와 착지, 좌측 경계, 피해 계산, 공격 재사용 대기,
피격 무적, 중복 없는 보상, 잘못된 선택 거부, 중복 선택 차단, 전체 런의 종료,
클리어 후 보상 차단, 사망 후 보상 차단, 새 런 초기화, 다른 시드 변화,
1,000개 시드의 안전한 생성과 보상 재현/런 전환을 검사했다.

추가로 25개 시드에서 자동 전투 플레이어가 실제 피해 계산으로 적을 처치하고 보상 선택과 보스 점프로 클리어했다. 이 테스트는 Unity 입력이나 인간 플레이의 재미·난이도를 검증하지 않는다.

Unity 편집기와 기기 빌드는 이 환경에 없어 아래 항목은 **미검증**이다.
