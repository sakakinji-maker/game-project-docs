# 2026-11-06 · HUD, 적 모션, 인식, 봉합과 최종 결말

## 이번 소스 반영 범위

- HUD: 상단 가로 장식선과 설정/정지·스킬·인벤토리 진입 버튼 제거. 미니맵 확대. Esc·K·I 키 유지.
- 모션: 일반 적 3종과 보스 7종에 각 24프레임, 총 240프레임 시트 추가. 이동·기본 공격·특수 동작을 분리하고 타격 시점을 기존 모델에 연결. 단일 몸 배율, 지상 발 접점, 가면 위치 및 마지막 보스 검 끝 경계를 보정.
- 인식: 화면에 몸 일부가 보이는 적을 완전히 숨은 적과 구분. 지상 추적에서 좁은 순찰 구역의 이동 제한을 해제하고 발판 위 적의 범위는 유지. 검 3타 넉백에도 동일 지상 경계를 적용.
- 2층: 열린 봉인 껍질 내부에 봉합 배치.
- 3층: 평행한 막대 표현을 제거하고 천체 장치에 곡선 봉합 배치.
- 5층: 거울 복구 면의 스캔라인 다각형을 제거, 정상 거울 이미지와 가는 봉합으로 복구.
- 6층: 일식이 사라진 공간에 맞춘 아치형 봉합.
- 7층: 어머니 포획체 상단으로 이어지는 두 곡선과 해방 시 소멸. 태양을 가로지르는 선 대신 상단 테두리의 봉합.
- 결말: 최종 스킬 선택을 마친 뒤 어머니 앞 지상에서 ↑를 누르면 결말 화면으로 이동. 기존 포탈 종료도 유지. 결말에 마을 귀환·장비 확인·새 모험 제공.

## 검증 범위

Core / Runtime / Editor / Tests 네 어셈블리의 컴파일을 확인했습니다. 컴파일 명령은 프로젝트 상위 `tools/Compile-AttackArt.ps1 -OutputFolder Temp/SealRescueFixCompile`입니다. 이 스크립트는 기존 Unity Library/Bee 참조가 필요하며, 새 체크아웃에서는 먼저 Unity 임포트가 필요합니다.

```text
Sunfall.Core exit=0
Sunfall.Runtime exit=0
Sunfall.Editor exit=0
Sunfall.Tests exit=0
```

이는 자동 테스트 실행 결과가 아닙니다. 이번 변경의 Play, 수동 QA, Test Runner 실행, Windows EXE 재빌드는 하지 않았습니다. 인식 및 최종 귀환 회귀 테스트 소스는 추가·컴파일한 상태입니다. 본인 재검증 결과는 별도 기록합니다.

모션 작업 시 10개 PNG의 RGBA·1024×1536 크기, 240개 프레임의 비어 있지 않음, 불투명 픽셀의 2px 프레임 경계 교차 없음, Point/압축 없음/밉맵 없음 설정을 확인했습니다. 이는 플레이 검증을 대체하지 않습니다. [이미지 생성 프롬프트](enemy-motion-v3-prompts.md).

## 소스와 EXE 구분

최신 소스와 에셋은 이번 GitHub 반영에 포함합니다. 기존 Windows QA Release `sunfall-qa-2026.11.05-1`은 이전 빌드이며 HUD·전체 적 모션·이번 인식/봉합/결말 변경이 포함되어 있지 않습니다. 최신 수정 확인에는 Unity에서 이 소스를 열거나 이후 새로 만든 EXE가 필요합니다.
