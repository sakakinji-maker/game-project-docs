## 장착과 획득

- I 또는 화면 오른쪽 위 인벤토리 버튼으로 열고, I / Esc / 닫기로 닫습니다. 화면 버튼으로 장착·해제하며 같은 부위는 교체합니다. 인벤토리 동안 전투·카메라·애니메이션이 정지합니다.
- 무기·방어구·장화·유물 각 1개. 화로의 심장과 성소의 인장은 동시에 장착할 수 없습니다.
- 첫 실행에는 장비가 없습니다. 5종을 모두 표시하되 미획득 장비는 장착할 수 없습니다.
- 보스 상자에서 미보유 장비 1개를 시드 기반 무작위로 지급합니다. 자동 장착하지 않습니다. 처음 5회 상자는 중복 없이 5종을 모을 수 있고, 전부 보유하면 수집 완료 안내와 물약만 지급합니다.
- 기존 물약은 상자를 열 때 즉시 HP 40을 최대 체력까지 회복하며 보관하지 않습니다. 상자는 1회만 열립니다.
- 마을 또는 현재 방의 적이 전부 죽은 상태에서만 변경합니다. 전투 중에는 열람만 가능합니다. 보스 연출 중에는 열 수 없고, 결과 화면에서는 확인만 가능합니다. 지상에서 구르기·시전·공격이 끝나야 변경할 수 있습니다.
- 획득·장착 직후 PlayerPrefs의 `sunfall.equipment.v1.` 키에 저장합니다. 사망·타이틀 이동·재도전·앱 재실행 후에도 유지합니다. 전투 진행 자체는 저장하지 않습니다.
- I는 인벤토리 전용으로 예약합니다. 이전에 I에 저장한 전투 조작은 충돌하지 않는 기본/대체 키로 복원합니다.
- 상인 구매와 대장장이 강화는 후속 구현을 완료했습니다. 세트 효과·무작위 옵션은 없습니다. 아이콘은 기존 고딕 HUD와 같은 코드 그래픽이며 캐릭터 도트의 의상은 바뀌지 않습니다.

## 능력치 적용 규칙

- 장검은 지상 3연타와 공중 베기에만 적용. 기본 24 → 26.4, 3타 38.4 → 42.24. 마법에는 적용하지 않습니다.
- 외투는 최대 HP 100 → 120. 런 시작은 해당 최대 HP로 시작합니다. 런 도중 장착은 현재 HP를 회복하지 않으며, 해제 시 HP가 새 최대치를 넘으면 잘라냅니다. 반복 장착으로 회복할 수 없습니다.
- 장화는 구르기 재사용 0.7 → 0.6초. 이동 거리·무적 시간은 동일합니다.
- 심장은 파동·창·고리 피해에 각각 1.12배 적용합니다.
- 인장은 파동 5 → 4.5초, 창 6 → 5.4초, 고리 8 → 7.2초. 이미 시작한 재사용 대기는 그대로 진행하고 다음 사용부터 변경된 시간이 적용됩니다.
- 기본값에 장착 효과를 계산하므로 반복 교체로 수치가 누적되지 않습니다. HP와 검 피해 표시, 스킬 재사용 표시도 적용 값을 사용합니다.
