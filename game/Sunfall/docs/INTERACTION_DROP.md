# NPC 상호작용과 발판 내려가기 (2026-10-28)

- 마을에서 Space를 새로 누르면 145px 이내의 가장 가까운 NPC와 대화를 시작합니다. 가장 가까운 NPC의 이름표가 금색으로 강조되고 `Space · 대화`가 표시됩니다. 가까운 NPC의 이름표를 클릭하거나 터치해도 대화할 수 있습니다.
- 대화 중 Space는 다음 문장으로 진행하며, 마지막 문장에서는 닫습니다. 키를 계속 누르고 있어도 문장을 연속으로 넘기지 않습니다. 기존 클릭 대화와 Esc 닫기를 유지합니다.
- 설정·일시정지·키 지정 중에는 NPC 상호작용이 실행되지 않습니다. Space는 마을 문맥의 고정 상호작용 키이며 기존 전투 키 설정은 변경하지 않습니다.
- 전투에서 아래 방향키(↓)를 누른 채 설정된 점프 키(기본 Alt)를 새로 누르면 발판 아래로 내려갑니다. 아래 입력은 점프 입력과 함께 고정 스텝까지 보관합니다.
- 착지한 발판 높이만 첫 하강 스텝에서 무시합니다. 더 낮은 발판은 정상적으로 받쳐주며, 같은 발판에도 다시 점프해 착지할 수 있습니다.
- 지면에서는 아래+점프로 바닥을 통과하거나 위로 뛰지 않습니다. 아래키만 누르면 발판에 그대로 서 있습니다. 구르기·마법 시전 중에는 기존 점프 제한과 동일하게 동작하지 않습니다.
- 하강 기능은 전투방과 보스방에 공통 적용되며, 마을의 수평 이동 방식은 유지합니다.
