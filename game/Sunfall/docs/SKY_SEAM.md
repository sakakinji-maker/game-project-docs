# 첫 균열의 금빛 봉합

적용일: 2026-10-30.

## 장면 흐름

- 1스테이지 보스 성소의 하늘에 검은 내부와 붉은 가장자리를 가진 찢어진 균열을 표시합니다. 월드 중앙의 배경에 고정하며 보스의 이동을 따라다니지 않습니다.
- 보스 처치 연출 약 0.35초의 기존 대화가 끝나면 연출을 재개합니다. 0.55초부터 주인공의 손 근처에서 금빛 실이 하늘로 올라가고, 1.95초까지 11개의 교차 바늘땀이 왼쪽부터 차례로 새겨집니다.
- 움직이는 빛의 끝과 작은 금빛 입자가 봉합 위치를 나타냅니다. 바늘땀은 넓은 틈을 가로지른 후 조여지며 검은 틈과 붉은 빛을 닫습니다.
- 1.95초에 봉합을 마친 뒤 짧게 입자가 떠오릅니다. 기존 2.0초 포탈 개방, 2.5초 상자 출현, 3.2초 조작 복귀 순서를 유지합니다.
- 카메라는 처음에는 쓰러진 보스를 비추고 0.5~0.95초에 하늘의 균열 쪽으로 이동합니다. 기존 마지막 0.6초 동안 주인공에게 돌아옵니다.

## 남는 자국과 상태

- 금빛 중앙선, 교차 바늘땀과 작은 매듭이 성소에 남습니다. 파티클 수명이나 렌더링 시계로 제거하지 않고 현재 모험의 BossDefeated / BossDefeatRemaining으로 완성 상태를 계산합니다.
- 기존 배경과 같은 수평 시차 및 수직 이동을 사용하므로 카메라가 움직여도 자국은 배경에 고정됩니다. 균열은 1280px 논리 화면 기준 중앙 카메라에서 약 X=640, Y=254에 보이며, 끝까지 걸어가도 하늘에 남은 자국을 볼 수 있는 배경 범위에 배치했습니다.
- 대화·일시정지·인벤토리 동안 봉합 진행과 입자 애니메이션도 멈춥니다. 대사를 건너뛰어도 기존 처치 연출을 재개하므로 봉합은 진행됩니다.
- 2스테이지에서는 이 성소의 균열을 그리지 않습니다. 새 모험은 기존 진행 규칙대로 보스를 다시 처치해야 봉합됩니다. 영구 저장 상태나 전투 판정은 추가하지 않았습니다.

## 구현과 검증

- `Runtime/SunfallGame.SkySeam.cs`: 균열, 금빛 실, 바늘땀, 빛의 끝, 입자와 완성된 자국.
- `Runtime/SunfallGame.Map.cs`: 배경 레이어 및 처치 카메라 연결.
- `Runtime/SunfallGame.Rewards.cs`: 봉합 완료 자막.
- 기존 IMGUI의 선·다각형·다이아몬드 그래픽을 사용한 동적 연출입니다. 새 이미지 에셋은 만들지 않았습니다.
- Core / Runtime / Editor / Tests / 독립 CoreChecks 컴파일 성공. 로그: `Temp/SkySeamCompile/compile.log`.
- 본인 요청에 따라 Play 모드, 자동 테스트 실행, 게임 QA, 플레이어 빌드는 하지 않았습니다. 실제 화면 가독성과 연출 속도는 본인 QA 대상입니다.
