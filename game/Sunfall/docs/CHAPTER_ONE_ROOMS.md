# 1탄: 빛이 사라진 숲과 붉은 날개의 성소

2026-10-27. 기존 숲·성소 배경과 석재 도트를 재사용하고, 방마다 색조와 배경 장식을 추가했습니다. 새 이미지 생성이나 전투 수치 변경 없이 네 공간의 동선과 적 조합을 구성했습니다.

## 진행

불씨 마을 → 숲 입구 → 무너진 정원 → 악마 주둔지 → 공중 보스 성소 → 2스테이지 포탈. 후속 지역은 `CHAPTER_TWO.md`를 참고하세요.

- 각 방 폭 64, 시작 X=2, 출구 X=61. 지면은 연속되어 낙사가 없습니다.
- 일반 방은 현재 방의 적 전원 처치가 개방 조건입니다. 보스는 세 전투방을 지나야 생성합니다.
- 잠긴 출구는 높이와 관계없이 X=60에서 이동을 제한합니다. 열린 문은 지상에 서서(Y<1, Grounded), 문(X=61)에서 1.6 이내에 접근한 뒤 ↑를 새로 눌러야 전환됩니다. 자동 전환은 없습니다.
- 방 전환 시 HP·공격력·최대 HP·누적 처치 수 유지. 위치·행동·쿨다운·투사체·카메라·보간 상태 초기화, 기존 입장 무적 1초 적용.
- 자동 회복, 증강, 능력치 보상, 중간 보상 화면 없음. 주둔지 끝 X=56~61은 잠시 멈출 수 있는 성소 앞 공간이며 회복 기능은 없습니다.
- 사망 후 재도전은 숲 입구부터 시작합니다.

## 전투방과 장식

| 방 | 목적 | 적 | 장식 |
|---|---|---|---|
| 숲 입구 | 검 연타·구르기로 지상 근접전 | 근접병 4 | 청록 숲, 따뜻한 등불, 꺼진 태양 문양, 낮은 비석 |
| 무너진 정원 | 발판을 타고 궁수에게 접근 | 근접병 4·궁수 2 | 두 무너진 아치, 마른 화단, 차가운 청록색 |
| 악마 주둔지 | 중갑병 앞뒤 이동과 고지대 궁수 공략 | 근접병 3·궁수 2·중갑병 2 | 목조 망루, 붉은 깃발, 보급 상자, 오염된 태양 문양 |
| 공중 보스 성소 | 높이 변경·돌진 경로 회피 | 비행 보스 1 | 기존 성소 배경, 거대한 깨진 문양, 사슬, 붉은 등불 |

장식은 충돌하지 않습니다. 밝은 윗면이 있는 석재 발판과 지면만 착지할 수 있습니다. 세 일반 방의 숲 파노라마는 공유하고 색조·장식·발판 배치로 구분합니다.

## 발판 좌표

표기: `(시작 X, 폭, 높이 Y)`.

- 숲: `(9,7,1.6)`, `(25,8,1.6)`, `(43,8,1.6)`.
- 정원: `(8,7,1.6)`, `(13,9,3.2)`, `(27,7,1.6)`, `(37,7,1.6)`, `(42,10,3.2)`.
- 주둔지: `(8,7,1.6)`, `(13,8,3.2)`, `(25,8,1.6)`, `(37,7,1.6)`, `(42,9,3.2)`.
- 성소: `(7,7,1.6)`, `(12,7,3.2)`, `(17,7,4.8)`, `(40,7,4.8)`, `(45,7,3.2)`, `(50,7,1.6)`.

높은 발판마다 아래 접근 발판이 겹치며 단차는 1.6입니다. 기존 단일 점프의 고정 스텝 최고 높이 약 2.27보다 낮게 설계했습니다. 성소 중앙 X=24~40 상공은 비워 지상 파동과 비행 돌진 예고가 읽히도록 했습니다.

## 적 좌표

표기: `종류 (X,Y) / 좌우 이동 범위`.

- 숲: 근접 `(14,0)/10~20`, `(29,0)/24~34`, `(43,0)/39~48`, `(52,0)/48~56`.
- 정원: 근접 `(12,0)/8~20`, `(29,0)/25~34`, `(40,0)/36~45`, `(54,0)/50~56`; 궁수 `(19,3.2)/14~21`, `(49,3.2)/43~51`.
- 주둔지: 근접 `(12,0)/9~17`, `(30,0)/27~35`, `(53,0)/49~55`; 궁수 `(19,3.2)/14~20`, `(48,3.2)/43~50`; 중갑 `(22,0)/17~26`, `(40,0)/36~45`.
- 성소: 보스 `(32,2.2)`, 좌우 이동 범위 `8~56`, HP 220. 지면 파동·돌진·붉은 마법탄·HP 절반 이하 2페이즈 유지.

궁수의 이동 범위는 발판 안쪽으로 제한했습니다. 배치는 고정이며 현재 시드에 따라 변경되지 않습니다.

## 확인 범위

Unity 6000.3.27f1 내장 Roslyn과 프로젝트 Bee 응답 파일의 참조·분석기 설정으로 Core / Runtime / Editor / Tests를 컴파일했습니다. 로그: `Temp/ChapterOneRoomsCompile/compile.log`.

진행 순서, 방별 봉인, 궁수 이동 범위의 발판 지지, 높은 발판의 접근 경로 테스트 소스를 갱신했습니다. 테스트 코드는 컴파일만 했고 실행하지 않았습니다. Unity Play, 실제 플레이 QA, 플레이어 빌드는 하지 않았습니다. 전투 난이도와 화면상 가독성은 본인 QA 대상입니다.
