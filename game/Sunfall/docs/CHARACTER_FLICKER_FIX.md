# 캐릭터·NPC 반복 반짝임 수정

2026-11-01.

기존 DrawBlendedPose는 이전 프레임을 1-w, 다음 프레임을 w 투명도로 순서대로 그렸습니다. 일반 source-over 합성에서는 두 프레임의 불투명 몸통이 겹쳐도 최종 불투명도가 1이 되지 않습니다. w=0.5일 때 0.5 + 0.5×(1-0.5) = 0.75여서 배경이 25% 비칩니다. 프레임마다 진함 → 옅음 → 진함이 반복돼 대기 중에도 깜빡임처럼 보일 수 있습니다.

공통 렌더링을 DrawCharacterPose로 변경해 현재 애니메이션 프레임 한 장만 표시합니다. 이전/현재 포즈 캐시와 투명도 전환 계산을 제거했습니다. 주인공, 대장장이, 상인, 아린, 일반 악마, 1~7층 보스 모두 같은 방식으로 표시합니다.

보존 사항:

- RenderPosition의 위치 보간과 이동/카메라 처리.
- 기존 공격 중간 프레임, 선택 타이밍, 발 기준 위치, 스케일, 좌우 반전, 구르기 회전.
- 피격 및 구르기 상태의 의도된 색상 표시.
- 보스 등장과 사망의 의도된 투명도 효과.

프레임 사이를 반투명하게 섞는 효과는 사라지고, 도트 애니메이션은 원래 프레임 순서에 맞춰 교체됩니다. 이미지 파일은 수정하지 않았습니다.

주요 파일: `Assets/Sunfall/Runtime/SunfallGame.Motion.cs` 및 Hero, VillageNpcs, Demons, Boss, ChainBoss, SolarBoss, LateBosses의 호출부.

컴파일 로그: `Temp/CharacterFlickerCompile/compile.log`. 코드 검토 및 컴파일만 수행하며 Unity Play·게임 QA·테스트 실행은 하지 않습니다. 실제 표시 확인은 본인 QA 대상입니다.
