## 버그 리포트

### BUG-01 공중 공격 후 착지해도 공격 자세가 남음 — Major / P2

- **재현:** 발판 위 점프 → 공중 베기 → 착지 → 점프 없이 걸어서 발판 아래로 내려감
- **기대 / 실제:** 일반 낙하 자세 / 이전 공중 공격 회수 자세가 다시 표시됨
- **원인:** 착지 시 AirAttack·AttackStage 상태가 초기화되지 않음
- **수정:** 착지 상태에서 공격이 끝난 경우에만 상태 정리 (착지 순간 진행 중 타격은 유지)
- **재발 방지:** `AirAttackRecoveryTests` 회귀 테스트 3개 추가

### BUG-02 캐릭터가 대기 중에도 깜빡임 — Major / P1

- **재현:** 마을에서 캐릭터를 세워 두고 몸통 관찰
- **기대 / 실제:** 항상 불투명 / 진함 → 옅음 반복, 배경이 비침
- **원인:** 두 프레임을 1−w, w 투명도로 겹쳐 그림. w = 0.5일 때 불투명도 0.5 + 0.5 × 0.5 = 0.75 → 배경 25% 노출
- **수정:** 현재 프레임 한 장만 그리도록 공통 렌더링 교체. 피격·사망 연출의 의도된 투명도는 유지
- **영향 범위:** 주인공, NPC 3종, 일반 몬스터, 보스 7종 호출부 전체 확인 — [상세](../game/Sunfall/docs/CHARACTER_FLICKER_FIX.md)

### BUG-03 미니맵 위에 스킬창 버튼이 겹침 — Minor / P3

- **재현:** 전투방 진입 → 화면 상단 확인
- **기대 / 실제:** 겹침 없음 / 미니맵 x = 838~1072 위에 버튼 x = 925~1080
- **수정:** 전투 중 스킬·인벤토리 버튼을 설정 버튼 아래 세로 배치 — [상세](../game/Sunfall/docs/REVIEW_FIXES_2026_11_02.md)

## 밸런스 QA: 장비를 껴도 강해진 느낌이 없다

먼저 계산 누락(버그)인지 확인했습니다. 모든 공격 경로가 같은 피해 함수를 써서 계산 오류는 없었고, **수치 설계 문제**로 판단했습니다. 처치에 필요한 타수가 변하지 않으면 플레이어는 차이를 느끼지 못합니다.

| 장검 상태 (성장 0) | 1타 | 3연타 합 | 근접병 HP 44 | 중갑병 HP 100 |
| --- | ---: | ---: | ---: | ---: |
| 미장착 | 24 | 86.4 | 2타 | 4타 |
| 조정 전 +0 (+10%) | 26.4 | 95.04 | 2타 | 4타 |
| 조정 후 +0 (+30%) | 31.2 | 112.32 | 2타 | 3타 |
| 조정 후 +5 (+70%) | 40.8 | 146.88 | 2타 | 3타 |

- **조정:** 장검 +10% → +30%, 화로의 심장 +12% → +25%. 장착 전후 피해 비교 UI와 피해 숫자 표시 추가
- **검증:** 강화 0·1·5 × 지상·공중 6가지 조합에서 표시 피해 = 실제 HP 감소를 회귀 테스트
- **남은 관찰:** +5에서도 근접병 처치 타수는 2타(40.8 < 44). 다음 밸런스 검토 항목 — [상세](../game/Sunfall/docs/EQUIPMENT_DAMAGE_FEEDBACK.md)
