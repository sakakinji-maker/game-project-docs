정리일: 2026-11-06. 사용자가 이 대화에서 직접 관찰·제보한 내용을 묶은 기록입니다. 반복 보고는 동일 항목 아래에 합쳤습니다. 원문에 없는 재현 횟수, 정확한 빌드 번호, FPS, 수정 후 성공률은 기재하지 않습니다.

## 상태 읽는 법

- **사용자 확인:** 사용자 발언으로 해당 현상의 개선 또는 정상 동작이 확인됨. 이후 빌드 전체에 대한 보증은 아님.
- **제보 / 재확인 필요:** 실제 플레이에서 문제를 보고했으나 수정 후 명시적인 확인 발언이 없음.
- **개선 요청 / 재확인 필요:** 품질·가독성·규칙 개선 요청이며 반드시 기능 결함을 뜻하지 않음.
- 최신 7건은 코드 수정과 컴파일을 확인했지만 **수동 재검증 대기**입니다.

| 근거 발언 | 확인 가능한 범위 | 확대 해석하면 안 되는 범위 |
|---|---|---|
| “다 잘 동작하는걸 확인했어” | 초기 검 3연타·공중 베기·구르기·불씨 파동 구현 뒤 정상 동작 보고 | 이후 추가된 보스·장비·스킬·전체 캠페인 |

| “오류 없는데?” | 당시 사용자가 Unity 오류가 없다고 응답 | 모든 런타임 동작 및 자동 테스트 통과 |

## 이 기록으로 확인할 수 있는 QA 활동

입력과 조작, 전투 표현, 적 AI, 진행 조건, 보상 규칙, 저장, 장비 체감, 화면 가독성과 연출까지 직접 플레이 피드백을 남겼습니다. 개선된 항목을 부분 확인한 뒤 남은 문제를 다시 지적하는 방식으로 반복 검토했습니다.

이 문서는 수동 QA **제보 및 관찰 실적**을 보여줍니다. 표 전체의 수정 검증 완료, 전체 테스트 통과, 모든 스테이지 완주 성공률을 증명하는 자료는 아닙니다. 최신 상세 리포트의 재검증 결과 칸은 사용자 확인을 받은 뒤 갱신합니다.
