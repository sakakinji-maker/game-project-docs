## 2. 기획 의도

- 왜 이 게임을 만드는가: 내가 좋아하는 캐릭터 ( 실물 사람은 안됨 )로 게임을 하고 싶음
- 세계관 : 핵전쟁 이후의 디스토피아 (폐허가 된 도시, 변이 몬스터 등)
- 이 게임만의 차별점 : ai로 만든 캐릭터 사용 예정. 초반엔 권총 한 자루로 시작해서 점점 강력한 무기로 성장하는 재미
- 타겟 유저: 짧게 반복 플레이하며 성장하는 재미를 좋아하는 캐주얼 유저

---

## 3. 핵심 게임플레이 (Core Loop)

```
1. 캐릭터는 방향키/WASD로 이동만 하고, 무기는 자동으로 발사/공격한다.
2. 몬스터가 화면 바깥에서 계속 스폰되어 플레이어 쪽으로 이동한다.
3. 몬스터에 닿으면 플레이어가 데미지를 입는다 (체력 0이면 게임오버).
4. 무기 공격으로 몬스터를 처치하면 경험치 젬을 드랍한다.
5. 경험치 젬을 주우면(또는 자동 흡수) 경험치가 쌓이고, 일정량이 되면 레벨업한다.
6. 레벨업 시 "신규 무기 획득 / 기존 무기 강화 / 스탯 강화" 중 3개 카드가 뜨고 하나를 선택한다.
7. 시간이 지날수록 몬스터 수와 강함이 늘어난다 (웨이브 진행).
8. 목표 생존 시간을 채우면 클리어, 체력이 0이 되면 게임오버.
```

정리하면: **이동(조작) → 자동 전투(시스템) → 처치/경험치 획득 → 레벨업 선택 → 난이도 상승 → 반복**

- 이 장르의 핵심은 "내가 직접 공격 버튼을 안 눌러도 되고, 이동/선택에만 집중한다"는 점이에요. 조작이 단순해서 캐주얼하게 즐기기 좋아요.

## 4. 조작법

| 조작 | 동작 |
|---|---|
| 방향키 / WASD | 캐릭터 이동 (공격은 자동) |
| 마우스 클릭 (레벨업 시) | 3가지 카드 중 하나 선택 |
| ESC / P | 일시정지 (선택) |

---

## 5. 승리/패배 조건

- 승리(클리어) 조건: 목표 생존 시간(예: 15분) 도달
- 패배(게임오버) 조건: 체력이 0이 됨
- 점수 계산 방식: 생존 시간 + 처치한 몬스터 수를 합산한 점수 (예: 생존 1초당 1점 + 처치 1마리당 1점)

---

## 6. 화면 구성 (플로우)

```
타이틀 화면 → (캐릭터 선택, 선택사항) → 플레이 화면 → 레벨업 선택 팝업(반복) → 게임오버/클리어 화면 → (다시하기 / 타이틀로)
```

### 타이틀 화면
- 게임 제목, "시작하기" 버튼, 최고 기록(생존시간/처치수) 표시

### 플레이 화면
- 캐릭터, 몬스터들, 화면 상단에 체력바 / 생존 시간 / 레벨·경험치 바
- (선택) 처치 수, 획득한 무기 아이콘 목록

### 레벨업 선택 팝업
- 경험치가 다 차면 게임이 잠시 멈추고 카드 3장 표시 (신규 무기 / 무기 강화 / 스탯 강화)

### 게임오버 / 클리어 화면
- 최종 생존 시간, 처치 수, 점수, "다시하기" 버튼

## 7. 난이도 / 스테이지 구성

시간 흐름에 따른 웨이브(난이도) 테이블 예시:

| 구간 | 몬스터 구성 | 비고 |
|---|---|---|
| 0~2분 | 약한 몬스터 소수 | 튜토리얼 성격, 여유 있게 적응 |
| 2~5분 | 몬스터 수 증가, 이동속도 다양화 | 첫 위기 구간 |
| 5~10분 | 다수 + 엘리트(체력/공격 강화) 몬스터 등장 | 무기 조합이 중요해지는 구간 |
| 10분~ | 보스 또는 물량 폭증 | 클리어 직전 최종 난이도 |

(작성) — 실제 몬스터 종류/수치는 게임 컨셉에 맞게 조정 필요

## 8. 필요한 리소스

### 그래픽
- 캐릭터: 핵전쟁 디스토피아 생존자 컨셉(방독면/방호복 등), 이동 애니메이션(걷기 4~8프레임 정도)
- 몬스터: 변이체/방사능 괴물 계열 최소 2~3종 (일반/빠른형/탱커형)
- 무기: 권총(시작) → 샷건/기관단총/레일건 등으로 단계적으로 강력해지는 무기 스프라이트
- 배경: 폐허가 된 도시/황무지 타일
- 이펙트: 무기 투사체, 피격 이펙트, 레벨업 이펙트
- 확보 방법: 초기 프로토타입은 원/사각형 같은 단순 도형으로 대체 → 재미 검증 후 무료 에셋(itch.io 등)이나 직접 제작으로 교체 추천

### 무기 성장 예시
| 단계 | 무기 | 특징 |
|---|---|---|
| 시작 | 권총 | 느린 연사, 낮은 데미지 |
| 초반 강화 | 기관단총 / 샷건 | 연사속도 또는 범위 증가 |
| 후반 | 레일건 / 화염방사기 등 (작성) | 강력한 광역 데미지 |

### 사운드
- 효과음: 피격음, 처치음, 레벨업음
- BGM: 긴장감 있는 루프 음악 1곡
- 확보 방법: 무료 효과음/BGM 사이트 활용

## 9. 기술적 고려사항

- 사용 기술: HTML5 Canvas + `requestAnimationFrame` 기반 실시간 렌더링 루프 (원카드처럼 DOM/CSS 방식이 아니라, 동시에 움직이는 오브젝트가 수십~수백 개라 Canvas가 적합)
- 충돌 처리: 원형 충돌(캐릭터-몬스터, 투사체-몬스터 사이 거리 계산)로 단순화, 오브젝트 수가 많아지면 성능을 위해 오브젝트 풀링 고려
- 저장할 데이터: 최고 생존 시간/처치 수는 localStorage에 우선 저장, 필요하면 원카드 때처럼 서버+DB로 확장해 랭킹 기능 추가 가능
- 예상 개발 난이도: 중~상 — 턴제였던 원카드와 달리 실시간 루프, 다수 오브젝트 충돌, 밸런싱(난이도 곡선)까지 다뤄야 해서 반복 튜닝이 많이 필요함
- 개발 순서 제안:
  1. 캐릭터 이동 + 몬스터 스폰/추적 + 충돌로 데미지만 있는 프로토타입
  2. 자동 공격 무기 1종 + 경험치/레벨업 시스템 추가
  3. 무기 종류 2~3개 추가 + 웨이브(난이도) 테이블 적용
  4. 그래픽/사운드 다듬기
  5. (선택) 최고 기록 온라인 랭킹보드
