## 2. 기획 의도

- 왜 이 게임을 만드는가: 대한민국에는 엄청 많은 생태계교란종이 있지만 사람들은 모르는 경우가 있어서 그것을 알려주기 위해서
- 세계관 / 스토리 컨셉: 현대 대한민국 / 주인공이 대한민국에 생태계교란종들을 잡으러 가는 컨샙 ( 사람 vs 동물 ) 사람은 도구를 사용함
- 이 게임만의 차별점: 잡은 생태계교란종은 파티원으로 키우는 게 아니라 "도감(컬렉션)"에 등록만 됨 (현실에서 생태계교란종은 사육이 불가능하다는 점을 반영). 전투는 주인공이 직접 도구로 싸우고, 도감 완성이 수집 목표가 됨
- 타겟 유저: 천천히 성장하고 스토리를 즐기는 유저

## 3. 핵심 게임플레이 (Core Loop)

```
1. 맵(필드)을 방향키/WASD로 돌아다닌다.
2. 필드의 생태계교란종(동물 또는 식물)과 부딪히거나 일정 확률로 전투가 시작된다 (인카운터).
3. 전투 화면으로 전환되고, 턴이 되면 "공격 / 스킬 / 포획(또는 채집) / 아이템 / 도망" 중 명령을 고른다.
   - 상대가 동물이면 "포획", 식물이면 "채집"으로 명령어 이름만 다르게 표시되고 내부 동작은 동일하다.
   - 식물은 공격을 하지 않는다 (대신 가시박처럼 가시가 있는 종은 접촉 시 소량의 반사 데미지를 줄 수 있음). 동물은 일반적으로 반격한다.
4. 공격으로 상대 체력을 낮춘 뒤 "포획/채집" 명령으로 도구를 사용한다.
   - 성공률은 상대의 남은 체력이 낮을수록 높아진다 (포켓몬의 몬스터볼과 같은 방식).
   - 성공 시 도감에 등록되고 전투가 즉시 종료된다 (죽이거나 뽑아버리는 게 아니라 채집하는 것으로 취급).
   - 실패 시 도구만 소모되고 상대의 턴이 이어진다 (식물은 반격이 없으니 사실상 페널티가 적음). 그냥 물리쳐서(체력 0) 전투를 끝낼 수도 있다.
5. 전투가 끝나면 경험치·골드를 얻고, 경험치가 차면 레벨업(능력치 상승)한다.
6. 다시 필드로 돌아와 이동, NPC와 대화, 마을에서 포획/채집 도구·장비 구매 등을 한다.
7. 스토리 진행에 따라 새 지역이 열리고, 그 지역의 생태계교란종(동물+식물)을 모두 도감에 등록하면 다음 단계로 넘어간다.
```

정리하면: **필드 이동 → 전투 진입 → 약화시키기 → 포획 시도(또는 처치) → 도감 등록/성장 → 필드 복귀 → 스토리 진행 → 반복**

## 4. 조작법

| 조작 | 동작 |
|---|---|
| 방향키 / WASD | 필드에서 캐릭터 이동 |
| 스페이스 / 엔터 | NPC와 대화, 상자 열기, 상호작용 |
| 마우스 클릭 (전투 중) | 공격/스킬/포획(식물이면 채집)/아이템/도망 명령 선택, 대상 선택 |
| 클릭 (필드 중) | 메뉴 열기 (인벤토리/스탯/저장) |

## 5. 승리/패배 조건

- 전투 종료 조건 (셋 중 하나):
  1. 포획/채집 성공 → 도감에 등록, 전투 종료
  2. 상대 체력 0 (처치/제거) → 전투 종료, 경험치/골드만 획득 (도감 등록은 안 됨)
  3. 도망 성공 → 전투 취소 (식물 상대로는 위험하지 않으니 도망 대신 그냥 포기하고 나가는 것과 비슷)
- 전투 패배 조건: 주인공 체력 0 → (작성: 게임오버로 처리할지, 마을로 페널티 귀환할지)
- 최종 목표: (작성 — 예: 도감 완성 100%, 특정 지역의 생태계교란종 문제 해결 후 엔딩)
- 성장 요소: 레벨업 시 체력/공격력/방어력 등 능력치 자동 상승 (+ 일정 레벨마다 새 스킬/도구 습득)
- 수집 요소: 도감에는 종류별 이름·설명·왜 생태계교란종인지·포획 여부가 기록됨 (기획 의도의 "알리기" 목적과 연결)

## 6. 화면 구성 (플로우)

```
타이틀 화면 → 필드(맵) 화면 ⇄ 전투 화면 / 대화창 / 메뉴(인벤토리·스탯·도감·저장) → 게임오버/엔딩 화면
```

### 타이틀 화면
- 게임 제목, "새 게임" / "이어하기"(저장 데이터 불러오기) 버튼

### 필드 화면
- 캐릭터, 맵(타일), NPC, 몬스터 오브젝트
- 좌상단 파티 요약(체력/레벨), 메뉴 버튼

### 전투 화면
- 주인공 체력/마나 바, 상대 생태계교란종 체력 바 (정확한 수치 대신 대략적인 게이지로만 보여줄지는 (작성))
- 하단 커맨드 메뉴: 공격 / 스킬 / 포획 / 아이템 / 도망
- 포획 시도 시 성공/실패 연출 (포켓몬 볼처럼 도구를 던지는 간단한 이펙트)
- 전투 로그(누가 무엇을 했는지 텍스트로 표시)

### 도감 화면
- 지금까지 만난/잡은 생태계교란종 목록 (실루엣 처리 후 잡으면 정보 공개)
- 각 항목: 이름, 설명, 어떤 피해를 주는 생태계교란종인지, 포획 여부, 완성률(%)

### 메뉴 화면
- 인벤토리(포획 도구 개수 포함), 스탯, 장비, 도감, 저장/불러오기

## 9. 기술적 고려사항

- 사용 기술: 필드 이동은 Canvas 기반 타일맵, 전투 화면은 커맨드/텍스트가 많아 DOM(HTML/CSS) 기반이 더 적합 — 화면 종류에 따라 혼합해서 사용
- 저장할 데이터: 주인공 스탯, 인벤토리(포획 도구 수), 도감 등록 현황, 현재 위치, 진행 상황(퀘스트/스토리 플래그)을 localStorage에 저장 — RPG는 이어서 하는 게 기본이라 저장 기능이 핵심
- 예상 개발 난이도: 상 — 맵 데이터, 전투 밸런스, 대화/퀘스트 시스템, 저장/불러오기까지 챙길 게 많아서 원카드·서바이벌보다 범위가 큼
- 개발 순서 제안:
  1. 맵 이동 + 몬스터 접촉 시 전투 화면 전환(인카운터) 프로토타입
  2. 턴제 전투 커맨드(공격만) 구현 — 승리/패배 판정까지
  3. 스킬/아이템/파티(여러 캐릭터) 시스템 추가
  4. NPC 대화, 상점, 퀘스트 추가
  5. 저장/불러오기 구현
  6. 여러 지역 + 보스 추가, 엔딩

## 11. 기타 메모

- "생태계교란종"은 환경부가 법적으로 지정한 외래 침입종을 뜻하는 용어라(예: 뉴트리아, 황소개구리, 붉은귀거북, 블루길, 배스, 큰입배스 등), 멧돼지·까치처럼 개체수 조절 대상인 "유해야생동물"(토종이지만 개체수가 많아 관리 대상인 것)과는 다른 개념임 — 도감에 넣을 종은 실제 환경부 고시 목록을 기준으로 정확하게 선정해야 "알리기" 취지에 맞음
- 동물 + 식물 둘 다 포함하기로 결정. 같은 전투 화면/포획 시스템을 재사용하되, 식물은 반격하지 않는 "수동형" 상대로 처리하고 명령어 이름만 "채집"으로 다르게 표시 (엔진은 하나로 통일해 개발 부담을 줄임)
- (작성) — 스토리 개요, 캐릭터 컨셉, 참고 이미지 링크 등 자유롭게
