## 2. 기술 스택 (추천)

게임 개수가 많지 않고 처음 만드는 프로젝트라면 아래 스택을 추천합니다. 빌드 도구 없이 바로 브라우저에서 실행되고, 게임을 하나씩 늘려가기 쉽습니다.

| 영역 | 추천 | 비고 |
|---|---|---|
| 프론트엔드 | 순수 HTML / CSS / JavaScript | 빌드 설정 없이 바로 배포 가능 |
| 게임 렌더링 | Canvas API (2D 게임 기준) | 라이브러리 없이도 충분, 필요시 Kaboom.js/Phaser 등으로 확장 |
| 배포 | GitHub Pages / Netlify / Vercel | 정적 사이트라 무료 배포 가능 |
| 데이터 저장 (랭킹 등, 선택) | localStorage → 필요해지면 Firebase | 처음엔 서버 없이 시작 |

> 게임 수가 많아지거나 회원가입/랭킹/저장 기능이 커지면 → React + 백엔드(Firebase, Supabase 등)로 전환 고려.
> 기술 스택: (작성 — 위 추천을 쓸지, 다른 걸 쓸지)

## 5. 폴더 구조 (예시)

```
project-root/
├── index.html              # 홈 화면
├── games.html               # 게임 목록
├── /assets
│   ├── /images
│   └── /sounds
├── /css
│   └── style.css
├── /js
│   └── main.js
└── /games
    ├── /game-a
    │   ├── index.html
    │   ├── game.js
    │   └── style.css
    ├── /game-b
    │   └── ...
    └── /game-c
        └── ...
```

> 게임마다 폴더를 분리해두면, 게임 하나를 추가/삭제/수정할 때 다른 게임에 영향을 주지 않습니다.
